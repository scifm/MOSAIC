# Hypothesis H2 (ctrl-b): joint (G,R) orbit classes carry the gain; the star product dilutes it

**Family:** `w3-joint`, w3 parent. The block only takes products of real star
functions, but with 2-member stars {±G_i}, {±R_j} it can express C6-symmetric
joint classes J_c = Σ_i O_{±G_i}(r) F_{±R_(i+c)}(k), c = 0,1,2, labelled by the
physical angle between G and R (mod 180°). The star product is
O_S F_T = (1/3) Σ_c J_c (checked numerically). sin·sin joint terms are not
representable.

**Evidence so far (s21, amplitude a_c = ±0.03 per class):**
- S1×T1: G ⊥ R class (90°): +0.03 → 1.0622, −0.03 → 0.8963; the ±30° pair: ≈ 0.97 both signs.
- S3×T1: G ∥ R class (0°): +0.03 → 1.0590, −0.03 → 0.9029; the ±60° pair: ≈ 0.975 both signs.
- Product family at its best (α = 0.05 on both, i.e. a_c = 0.0167 in every class): s21 1.034, r46 1.050, r56 1.043.
So the gain sits in one class per star and the other classes only add curvature.

**Plan / box.** 2D grid in (a[S1T1,⊥], a[S3T1,∥]) ∈ {0.03, 0.05, 0.07}² plus 1D rays to 0.09; class scans
(±0.03) for S4, S9, S16 (⊥ and 30° pair) and S12 (∥ and 60° pair) with T1; then
chiral S7a/b and T2. Box: |a_c| ≤ 0.15 to start, widened if winners sit on the edge.
Then a local optimizer (Nelder–Mead / CMA-ES, few dims) over the classes with positive linear terms.

**Expected sign:** R_gap − 1 > 0 along the gain classes, concave; the 1D quadratic
reads predict ≈ +8 % each at a_c ≈ 0.06 on Nk = 21.

**Budget:** ≈ 120 evaluations for this family.

**Mechanism caveat:** amplitude, so M2^(k) changes; a matched-density static control
will be requested for any finalist.
