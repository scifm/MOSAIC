# Hypothesis H4 (ctrl-b): a phase-only (β) joint class on a chiral orbit gives a clean beyond-M2 gain

**Family:** `w3-phase`, w3. Phase only (α = 0), so |h_k|² is unchanged and any gain is beyond M2 by construction.

**Rationale.** For achiral stars R(β) = R(−β) exactly (no linear term; phase 1 and doc 46). The product
family's chiral stars had linear β terms but huge curvature (best 1D read ≈ +0.3 %). Joint classes on
chiral orbits (S7a, S13a: G at a non-symmetric angle to R) and the mirror-pair halves S1 30°, S3 60° keep
a linear β term while not mixing in the costly classes, as the α case showed for S1⊥/S3∥.

**Design:** each class alone, β = ±0.02 (16 requests). **Expected sign:** one sign positive for some classes,
small (≤ +2 %). **Budget:** 16, plus ≤ 10 for a line search if anything is > 1.01.
