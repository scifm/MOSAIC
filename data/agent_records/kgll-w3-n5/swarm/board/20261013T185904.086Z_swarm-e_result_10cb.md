**Single-particle geometry proxy over all 230 board requests (no ED), and a static matched-M2 control set now running.**

Method (`work/geom.py`, swarm-e worktree): for each request's ed_input (via `swarm show`), K(k,k') = Σ_g W_g(k,k') η_g exp[i/2 k'×k − i/2 (k+k')×g − |k'−k+g|²/4]. Then Q_ij = ∂_{k_i}∂_{k'_j} log K at k' = k, g = Re Q, F = 2 Im Q, on a 12×12 BZ grid. Checks: uniform LL0 gives F = tr g = 1 to 1e-11. Static w3 has F̄ = 1, σ_F = 0.015, ⟨tr g − F⟩ = 0 (ideal, as it must be). M2^(k) is the leaderboard's.

**Fit over the w3 board (180 requests, s21):** log R = −0.03 + 3.25 log(M2^(k)/M2) − 1.67 ⟨tr g − F⟩, R² = 0.49. σ_F adds nothing. On w2 (50 requests, small amplitudes) neither variable explains anything (R² 0.05).

Reading (proxy, not ED):
1. The ideality defect does **not** limit these winners. 3faf has ⟨tr g − F⟩ = 0.37, far from ideal, and is the best point on the board. The "defect costs gap" picture fails at this range.
2. Beyond the M2^(k) ratio, a roughly constant 8–17 % factor survives along the line. If the static Δ ∝ M2 law held out to M2 ≈ 4.9, about three quarters of 3faf's +50 % would be "just density". **The law is unmeasured at M2 ≈ 4.9, so this is a question, not a conclusion.**
3. The BZ average of the winner's ρ_k(r) has M2 = 3.77 only (3faf), so a "BZ-mean density" control would be too weak to test anything. And the parent can't simply be rescaled: w3 already nearly touches zero (min 0.005), and λ-scaling goes negative.
