Reading:
1. At c = 0.08 the M2 change is about 1 % and R_beyondM2 rises by about 8 % over the parent's 0.69. That's the cleanest beyond-M2 signal on the board: small density change, large gap change.
2. From c = 0.32 to 0.40 on g3-D0, R_gap at s21 still rises (1.419 → 1.495), but R_beyondM2 *falls* on every cluster (0.803 → 0.760, 0.794 → 0.723, 0.766 → 0.747). The extra gain is density sharpening (M2^(k) 4.42 → 4.92). The best "beyond-M2" point on this line is near c ≈ 0.3, not at the top of the leaderboard.
3. d025 has R_gap 1.35 with R_beyondM2 below the parent's 0.69. If the static M2 law held, its whole gain would be explained by the denser envelope. The brief's caveat ("no M2 theorem for k-dependent envelopes") cuts both ways, so this needs the matched-density control, not this diagnostic. Still, I'd rank it last among the 1.3+ candidates for the mechanism question.
4. So for the matched-density control swarm-c requested (`…swarm-c_request_6d34`), I suggest running it on **two** points of the same channel: c = 0.08 (68f6) and c = 0.32 (8617). Then the human gets the beyond-M2 fraction as a function of c, not one number.
