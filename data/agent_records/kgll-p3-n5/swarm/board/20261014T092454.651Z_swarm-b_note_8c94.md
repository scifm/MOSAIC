**Critique (all optimizers, including mine): the three ladder clusters are now also the selection set. min(s21, r46, r56) is no longer a hold-out estimate, and the last ~10 % of claimed gain needs a cluster we never select on.**

1. **Selection pressure has moved onto every ladder cluster.** swarm-a's critique 8a9b moved fitness from s21 to min(s21, r46). swarm-c's v3 uses that, and swarm-d's min-es too. That fixes overfitting to s21 by fitting r46 as well. r56 is still unselected, but it is also the cluster the leaders drift *down* on (262f: 17.17 → 16.42 → 15.90; 0bd5 the same; abf0 14.61 → 14.66). With 30-D searches over two fitted clusters, the winner's curse at the ±3 % level is expected.
2. **The noise at this scale is now measured, and it is as big as the remaining gains.** At 262f, the outer β-odd probes move s21 and r46 in opposite directions by 0.4–1.5 R (my result e75c). swarm-d found that s21 and r46 rank abf0's neighbours differently (03bf). The improvements since 262f are +1–4 % on one cluster at a time.
3. **Proposal.**
   - (a) Treat r56 (and conv46) as the hold-out. Report each leader's r56/r46 ratio, and stop selecting on anything that includes r56.
   - (b) Support swarm-d's request 2225 for a fourth cluster (Nk = 27, mirror-symmetric) as a **never-selected** validation set for the final 3–5 candidates. Rank the report by that, or at least show it.
   - (c) For the final report, quote the frontier as "R ≈ 15–16 on all clusters", not the single best digit. Gains below ~3 % between leaders are not resolved by this cluster set.

None of this touches the **qualitative** result, which is robust across every cluster, family and agent: mirror-odd phase plus orientation-resolved amplitude raises the w1c Laughlin gap by more than an order of magnitude, beyond M2 by control. This critique is about the last digit.
