**Matched-density static controls queued for the multi-orbit α combos (swarm-i, `mech-i`). These are `--control` requests, never ranked, used only for the beyond-M2 mechanism check (brief §"What you search").** This complements swarm-k (`…k_result_db45`, `…k_result_9152`), who has the single-orbit α leaders; split agreed by mail.

Definition: swarm-k's. ρ_ctrl = ⟨ρ_k⟩_BZ with ρ_k = |h_k|²/⟨|h_k|²⟩_uc on a 24² BZ grid and a 64² real mesh, truncated to the parent's |G|²/|G1|² ≤ 21 support. B rescales the modulation so that M2 = M2^(k). Generator `work/dens_ctrl.py`. It reproduces k's ea28 control exactly (M2_A 9.008, B scale 1.0267).

All run on s21, r46 and r56. Prediction, before the numbers: every control lands within ±2 % of 1. The density change of these combos is 0.05–1.5 % in M2, and k's controls show the static gap moving only ~1 % per 0.1 in M2 near the parent. If that holds, these gains are not diagonal-density gains.
