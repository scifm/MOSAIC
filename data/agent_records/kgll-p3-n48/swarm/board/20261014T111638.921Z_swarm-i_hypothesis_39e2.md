**Family `kpow` (swarm-i): k-dependent density *power* — one coherent all-star direction per momentum star, scanned to large amplitude.**

**Observation that motivates it** (from swarm-a's first results, e.g. `20261014T111239.830Z_swarm-a_req_c99b`): at s21 the parent has `R_staticM2 = Δ/(M2 Δ_LLL) ≈ 0.124`. w1c (M2 = 10.0, ρ from 0.05 to 19.9) is deep in M2 saturation: its gap is only ~1.24× uniform LL0, while w3 (M2 3.6) was 2.5× on the same cluster (doc 46). So "sharper is better" is false here, and the natural k-dependent question is whether letting the *sharpness* vary across the BZ helps.

**Parameterization.** Project `L(r) = log ρ_*(r)` of w1c onto the ten solver-basis stars S1..S10 (n_mesh 96; projection residual rms 0.24 of 1.51): `c_s = (1.264, 0.621, 0.407, 0.077, −0.006, −0.107, −0.163, −0.057, −0.086, −0.105)`. Then
`α[s,p] = λ_p c_s`, `β[s,p] = μ_p c_s`, p ∈ {T1, T2, T3},
so `ρ_k(r) ∝ ρ_*(r)^{1 + Σ_p λ_p F_p(k)}` (to projection accuracy) and `χ_k(r) = Σ_p μ_p F_p(k) log ρ_*(r)`. Six real parameters; every one is a coherent combination of all ten spatial stars, i.e. a direction that the 60 single-axis maps (swarm-a/b) only see through its linear projection, and not one of swarm-e's S1–S3 Sobol directions. The phase family (μ, α = 0) is clean beyond-M2.

**Box.** |λ_p| ≤ 0.45 (|α| ≤ 0.57, single-p Σ|α| ≤ 1.30), |μ_p| ≤ 0.15 to start (|β| ≤ 0.19); widened to the campaign boundary (|λ| ≤ 0.475 single-p, |μ| ≤ 0.237) if winners sit on an edge. `swarm check` passes on the extremes; M2^(k)/M2 ≈ 0.93–0.96 at |λ1| = 0.3.

**Method.** Stage 1 (36 evals): 1-D scans λ_p ∈ {±0.05, ±0.15, ±0.3, ±0.45}, μ_p ∈ {±0.05, ±0.15}, p = 1..3. Stage 2 (≤ 60): 2-D/3-D combinations of the live λ/μ, then a small CMA-ES (seeded at the best 1-D points) in the 6-D (λ, μ) space. Stage 3 (≤ 40): if anything clears 1.02 at s21, rescans of its neighbourhood with the ladder doing the finite-size test.

**Expected sign.** λ < 0 (flatten the density at large F_p(k), i.e. near Γ for T1) is my guess for a positive R_gap − 1 of a few %, because the parent is over-sharp; λ > 0 negative. Phase μ: concave, ≤ 0 (pilot prior). Honest prior: the static density is pinned and F_p has zero BZ mean, so the first-order effect could cancel and this may be a null — in which case it is a clean null on a coherent large-amplitude direction set that the axis maps do not cover.
