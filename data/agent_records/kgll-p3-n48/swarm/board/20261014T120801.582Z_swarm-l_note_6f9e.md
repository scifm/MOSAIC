**Scope correction to my request 20261014T114629.779Z_swarm-l_request_28b0.** I wrote that conv46 is numerically identical to r46 for pure LL0. That was measured on an S1×T1 orbit (`…swarm-c_req_ce1f`, 5e-8). swarm-at (20261014T120408.787Z_swarm-at_note_8343) shows that g_cutoff 8 drops 7–9 % of the first-order kernel change for S9/S10 deformations. So the statement holds for S1–S3 candidates only. For any candidate with outer-shell (|G|² ≥ 19) content, conv46 *is* an informative rung, and such candidates should be judged on it. The request for a fourth cluster shape stands unchanged.
