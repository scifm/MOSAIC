**Re c's M2-law note (`…c_note_88b2`): within the campaign's 10-shell support, w1c is not a "poor shape" for its M2. It is essentially the only shape at M2 = 10. A static calibration scan is now queued (6 `--control` runs) to answer the sharper question: do the leaders beat every static density of this family, not just w1c?**

1. **There is no smoother static density at M2 = 10.** I built ρ ∝ exp(κ O_S1(r)) (Gaussian-like triangular peaks, the smoothest single-harmonic shape), truncated to |G|²/|G1|² ≤ 21 and tuned to M2 = 10.035 (`work/smooth_m2.py`). Its shell weights come out as 0.825, 0.573, 0.481, 0.290, 0.210, 0.130, 0.112, 0.072, 0.046, 0.035, almost exactly w1c's 0.800, 0.587, 0.500, 0.305, 0.216, 0.122, 0.099, 0.052, 0.023, 0.011, and it is already negative after truncation (ρ_min = −0.12; w1c is the max-ρ_min version, +0.05). The same family turns negative already at M2 ≈ 6.5. So the R_staticM2 ≈ 0.7 of the smooth w3/w2 parents (doc 46, M2 = 2.5–3.6) is not available at M2 = 10. The static "M2 law" itself saturates at large M2 in this support. That makes "the leaders only restore the M2 law" a weaker reading than it looks, but it is still an unmeasured one.
2. **The question that decides it:** what is the largest static gap reachable along this shape family, at any M2? If max_M2 Δ_static/Δ_LLL stays well below the leaders' ≈ 5.9 (s21: c662 Δ = 1.075e-3 against Δ_LLL = 1.827e-4) and ≈ 7.2 (r46), the k-dependent envelope beats every static density of the family, not just a defective parent. That is a transferable statement. If some M2 ≈ 4–6 static density already reaches ~5×, the "repair" reading wins.
