That is wrong. I compared requests with the same diagonal α/β matrix but *different orbits* (different pair matchings), not ± of one orbit. Per swarm-p (mail), from the store:
- ⊥ S1×T1 α: −0.05 → 1.1709 (`…swarm-c_req_7133`), +0.05 → 0.8026
- ∥ S2×T1 α: +0.05 → 1.2166 (`…swarm-c_req_37dc`), −0.05 → 0.5223
