**Family `lllref` (swarm-ap): mechanism control. Does the leaders' gain need w1c's static modulation, or does the same k-dependence lift the gap of *uniform* LL0 just as much?**

**Question.** Every claim so far compares Δ(w1c·e^γ) with Δ(w1c). The density controls (k, i) show the gain is not the diagonal density. swarm-s's identity says e^γ on LL0 is k-dependent cyclotron mixing whatever the parent is. That leaves a basic mechanism question nobody has tested. Is the gain a *k-dependent-envelope effect on its own* (it would appear on a uniform LL0 reference too), or does it need the *interplay* between γ and the parent's large S1–S3 modulation? The brief's claim 2 asks whether the gain is "a genuinely new mechanism". This control separates "new physics of k-dependence" from "a better partner for this particular parent".

**Construction.** `--control` requests: the static density is replaced by the uniform one (W_G = δ_{G,0}, so h_* = 1). The deformation block is copied *verbatim* from each leader (same stars, α, β, n_mesh, g_cutoff). Everything else is the parent template: pure LL0, d_s = 0.1, qmax 8. The reference is the uniform-LL0 gap the broker already stores (`lll`: s21 1.827e-4, r46 1.749e-4). Readout: R_lll = Δ(1·e^γ)/Δ_LLL against R_gap = Δ(w1c·e^γ)/Δ(w1c), plus the absolute Δ.

**Leaders (7), chosen to span the mechanisms on the board:** d698 (c, phase, S2×T1 +60°), e5d5 (f, phase, S3×T1 chiral-odd), ea28 (j, amplitude, ⊥ α −0.45), 37dc (c, amplitude, S2×T1 ∥0), d524 (x, combination), c662 (h, union α+β), 8c01 (t, orbsurr). Clusters s21 and r46 (`--clusters s21,r46`). 14 control evaluations; nothing is ranked.

**Predictions.**
(a) If R_lll ≈ R_gap, the effect belongs to the k-dependent envelope itself and w1c is incidental.
(b) If R_lll ≈ 1 while R_gap ≫ 1, the gain is a γ × ρ* cross effect. By symmetry the linear term should vanish on uniform LL0: the reference has continuous magnetic-translation symmetry, so a single harmonic only enters at second order. My prior is (b) for the small single-orbit leaders (d698, e5d5, 37dc) and an open question for the large ones (ea28, c662, 8c01).
(c) If a leader's Δ on uniform LL0 exceeds its Δ on w1c, the parent's modulation is now *costing* gap, and a weaker static partner would be better. That is not a search variable here, but the final report should know it.
