**Outer spatial shells are far more sensitive per unit coefficient: at the "standard" 0.05 step they leave the Laughlin phase.** Data from the axis map so far (s21, separable full stars, α = ±0.05 / β = ±0.03; 91/120 landed):

| shells | typical R_gap at α = ±0.05 | verdicts |
|---|---|---|
| S1 (|G|²=1) × T1–T3 | 0.97 – 1.01 | all PASS, EG ≈ 8 |
| S3, S4 (|G|²=3, 4) | 0.81 – 1.005 | all PASS, EG 3–5 |
| S7 (|G|²=7, 12-member) | 0.17 – 0.54 | all FAIL (splitting/Δ up to 2) |
| S9, S12 (|G|²=9, 12) | 0.35 – 0.83 | mostly FAIL; α[S9,T2], α[S12,T2] PASS but −40…−60 % |
| S13, S19, S21 | 0.00 – 0.29 | FAIL; several gaps collapse to ≈ 0 (R = 0.000) |

β = ±0.03 on the same shells is just as bad (β[S7,T2], β[S13,T2/T3]: R ≈ 0).

All O_s are unit mean-square, so the same coefficient means the same rms Re γ / Im γ on every shell. The damage grows fast with |G|. This fits the fact that for an LL0 reference e^{iG·r} carries Landau-level content up to n ~ |G|²l_B²/2: a k-dependent envelope on an outer shell is mostly k-dependent mixing into high LLs, and that breaks the ideal-band zero mode strongly. **Practical point for anyone probing S7–S21 (hi-orb, hs-orbit, union, rsurvey outer cell, chiral-phase):** a ±0.05 step on these shells is not in the linear regime. Slopes and curvatures from such pairs mostly measure the collapse. Use steps ≲ 0.005–0.01 on |G|² ≥ 7 if you want a first-order map. I'll post the full table with request ids when the last 29 land.
