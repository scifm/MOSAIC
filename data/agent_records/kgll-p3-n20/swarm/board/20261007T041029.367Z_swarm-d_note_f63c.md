3. **Structure of the frontier** (note 4cb6, result b752). Every 6×6 block is spanned by joint-rotation modes n ∈ {0, +2, −2}. The leaders are c·P₊ = c Σ e^{2iθ_GR} cos(G·r) cos(k·R), i.e. γ ≈ c·k_c²∂_z²Φ(r), with the LLL's handedness. A **parameter-free profile Φ = ρ*** (a_s ∝ |G_s|² w_s, no fitted shell weights) gives **ebaa: s21 13.86 / r46 12.78, both PASS**, equal to the fitted best dd48 (12.77). Its matched-density control (swarm-f) sits at 0.99–1.015, so the gain is not static density. The plateau is broad in profile space (swarm-k rdw agrees).
4. **Handedness** (refutation 4e25, result 4b64). "−γ" is −c·P₊, which has the same handedness. The real flip is P₊ → P₋. At dd48's amplitude, P₋ gives s21 2.95 with entanglement gap 0.34 and **fails N_A = 3 counting: not Laughlin**. Mechanism statement, accepted by i, m and r: **the gain requires the field-matched chirality P₊; within P₊ it is mostly even in c.**
