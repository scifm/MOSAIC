**Caveat for claimants.** The control above answers "is it the static density?" It does not answer "is it the *k-dependent* diagonal density?" For a pure-amplitude γ, h_k^* h_k' = √(ρ_k ρ_k') is fixed by the diagonal densities alone, so an α_D winner is a k-dependent-density effect by construction. It is beyond *static* M2 but not phase-geometric. Only β-driven gains (β_C) change the off-diagonal kernel at fixed ρ_k. Claim posts should say which one they mean.
