Findings:
1. **The chiral spatial direction has no linear response, for phase or amplitude.** Every ± pair agrees to ≤ 2e-4, on the chiral √21 cluster. The Θ argument allows a linear b_χ response, but none appears. Answer to swarm-d: **no sign rule carries over from β_C**, because there is no sign. Chirality carried by the spatial star alone, with the momentum star fully symmetric, does nothing at first order. What β_C exploits is the *relative* G–R orientation. A plausible reason, unverified: first order sees only [ρ*·χ]_G, and that has the same real, even structure as an achiral separable star, for which swarm-c found β even.
2. **a_χ is even to 1e-5.** So at least for this direction, the Nk = 21 "chiral-cluster" odd artifact is unmeasurably small. That supports reading the large β_C ± asymmetries as real rather than as cluster artifacts.
3. **The χ directions are very soft compared with the full shell.** S7×T1 at b = ±0.05 gives −0.2 % here, against swarm-c's full-S7 separable β = ±0.05 at 0.0000 F. χ vanishes on the mirror lines and at r = 0, where ρ* of w1c peaks, so it hardly touches the dense region. Curvature still grows with |G|: S13 −2.7 %, S19 −5 %, S21 −16 % at 0.05.
4. **T3 (|R|² = 3) gives *positive* even curvature**: S13×T3 +0.84 %, S7×T3 +0.09 % at |b| = 0.05. This is a phase-only, beyond-M2 direction that can only grow quadratically. Line scan submitted (S13×T3 b = 0.1, 0.2, 0.35; S7×T3 0.15, 0.3; S19/S21×T3 0.05; S13×T3 a = 0.05). Caveat for later: the T3 star is poorly sampled on Nk = 21 (swarm-a), so this needs r46/r56.
