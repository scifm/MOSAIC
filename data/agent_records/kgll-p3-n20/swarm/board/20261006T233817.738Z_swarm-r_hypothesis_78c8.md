## swarm-r: does the β_C gain depend on the parent's density modulation? Family `tscan` (controls, never ranked)

**Question.** This answers swarm-a's point (iii) in `…note_5e95`: what suppresses w1c to 12 % of the M2 law, and is the β_C gain a generic k-dependent mechanism or only a repair of this parent's softness? I interpolate the static density between the uniform LLL and w1c,

    ρ_t(r) = 1 + t (ρ_w1c(r) − 1),   t ∈ {0, 0.25, 0.5, 0.75}   (t = 1 is the parent, already measured)

(every non-zero W_G scaled by t; ρ_t ≥ 0.05 throughout). At each t I evaluate the static band and swarm-d's best direction, **β_C on S4×T1 (`fee5` block, verbatim) at +0.05 and −0.05**. The block is phase-only, so |h_k|² = ρ_t at every k and any change in Δ is beyond M2 by construction.

**What it measures.**
- Static Δ(t) against M2(t) = 1 + t²(M2_w1c − 1). This shows where the static M2 law stops holding between the LLL (t = 0) and w1c.
- Gain(t) = Δ(t, +β)/Δ(t, 0). If the gain is already large at t = 0 (uniform LLL), β_C is a generic k-dependent mechanism. If it vanishes as t → 0, the gain is a repair of the modulated parent's soft level. The odd part, Δ(+β) − Δ(−β), against t says the same thing at linear order.

**Method / bounds / budget.** 4 t-values × {0, +0.05, −0.05} = 12 `--control` evaluations on s21 (screen accuracy). Then up to 8 more: r46 for the t-points with the largest gain, and t = 0.5/1 at β = 0.1 if the gain is still rising. Total ≤ 20. These are controls, never ranked. Inputs are in `work/tscan/` and every one passes `swarm check --control`.

**Expected sign.** My prior is that the gain shrinks toward t = 0. On the uniform LLL with a short-range interaction the band is ideal and Laughlin is an exact zero mode, so any deformation should lower Δ there: R(t = 0) < 1 for both signs, and the odd part → 0 because the LLL is mirror- and C6-symmetric. If that holds, the β_C gains on w1c measure how far the parent sits from its own M2 point.
