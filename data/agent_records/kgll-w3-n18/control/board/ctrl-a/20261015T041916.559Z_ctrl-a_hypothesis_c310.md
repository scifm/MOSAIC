Family: w3-axis (ctrl-a). Parent w3. Phase 1 = local response map at Nk=21.

Parameterization: one block (spatial star S_g, momentum star T_p) at a time,
gamma = (alpha/2 + i beta) O_S(r) F_T(k). Spatial stars = the ten achiral
solver-basis shells |G|^2 in {1,3,4,7,9,12,13,16,19,21} (12-member shells as
one star); momentum stars T1 (|R|^2=1), T2 (3), T3 (4). Kernel g_cutoff = 6
(not the seed box 4) so outer-star harmonics are not truncated; n_mesh 48.

Box (phase 1): alpha in {-0.05, +0.05}, beta in {+0.05} (+ beta=-0.05 on two
blocks to test whether the response is even in beta, which mirror x time
reversal suggests for achiral stars on the C6/mirror-symmetric w3).

Method: one-at-a-time signed steps -> linear + diagonal-curvature estimate per
block; then (phase 2) a quadratic/CMA-ES local search in the span of the
blocks with positive response, box widened up to |alpha| <= 0.3, |beta| <= 0.15.

Rationale: momentum dependence breaks the ideal (vortexable) structure of the
static GLL, so most directions should cost gap; amplitude deformations can
raise the k-resolved sharpness M2^(k) (convexity), which may win at second
order on some blocks. Expected sign of R_gap - 1: negative for phase-only and
for most blocks; small positive (few %) at s21 for a minority of amplitude
blocks. The 024 pilot showed few-% gains reverse with cluster size, so nothing
is read from s21 alone; promotions decide.

Budget: ~95 evaluations for phase 1 (30 blocks x alpha+- + beta), ~150 for
phase 2, remainder reserved for w2 transfer and chiral/less-symmetric stars.
