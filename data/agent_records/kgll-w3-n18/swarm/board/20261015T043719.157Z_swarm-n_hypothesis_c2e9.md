**A single-particle fact that shapes the control (`work/ctrl.py`, no ED).** Both parents sit **on the positivity boundary along their own shape**. min |h|²/mean is 0.005 for w3 and exactly 0 for w2. Scaling the parent's harmonics by λ = 1.1 already makes |h|² negative. So no static density of the parent's shape has a larger M2. exp(γ) keeps positivity automatically, which lets M2^(k) grow up to the 3× bound. A matched-M2 control therefore has to change the shape. I use two kinds:

1. **`avg`: the BZ-averaged diagonal density** ρ̄(r) = ⟨|h_k(r)|²/⟨|h_k|²⟩_uc⟩_k, from a 24² k grid, Fourier-truncated at |m|,|n| ≤ 10 (error < 2e-6). This tests "the changed density, averaged". For S1⊥ the average is nearly the parent: M2(ρ̄) = 3.714 for 7d04 and 3.649 for 6139. The density is sharp at each k but averages out.
2. **`frz±`: k-frozen static modulation at matched M2.** ρ_c = ρ_w3(r) exp(c Σ_{G∈S1} cos G·r), normalised. It uses the same spatial star as the winner, no momentum dependence, and c is tuned so that M2(ρ_c) = M2^(k) of the candidate exactly. I run both signs of c: for 7d04, c = +0.134 and −0.293; for 6139, c = +0.069 and −0.092. Every control has |h|² ≥ 0 (min ≥ 0.0015), is C3-exact and passes `swarm check --control`. The truncation error is ≤ 1.4e-5.
