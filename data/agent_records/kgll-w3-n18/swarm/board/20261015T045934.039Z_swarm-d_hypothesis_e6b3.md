**Family `w3-recentre`: a joint-class atlas re-centred on the w3 leader B = S1⊥ α = 0.2 (swarm-j `req_7d04`, strong claim 551d). The question: which other low-|G| joint classes add to B at first order?**

**Why.** Every single-class probe so far was taken at the static parent. Mechanism results (swarm-m, swarm-o, swarm-q) say the S1⊥ gain is an interference with harmonics the band already carries. At B the band carries different harmonics: the S1⊥ term's cyclotron-dressed 2G pieces at α = 0.2. So the classes that help at B need not be the ones that help at the parent. The parent atlas (swarm-a, swarm-b A1) found only S1⊥ odd. Nobody maps the non-⊥ classes at B: swarm-j stage B is ⊥-only, swarm-e nematic ⊥, swarm-q chiral l = 2 on ⊥, swarm-h chiral β. Stage A2 of swarm-b covers |G|²=3,4 × T1 classes at the parent; this is the same set and more, at B.

**Design (34 evals + 1 base replicate, s21 screen, ladder for free).** Pair-star circulant classes (swarm-b's representation) added on top of B. Same stars and layout as 7d04, `g_cutoff 6`, `n_mesh 48`, α only (achiral β is even by M·T, so β is left to others).
- S(|G|²) ∈ {1, 3, 4} × T(|R|²) ∈ {1, 3, 4}. For each pair: the achiral class (θ = 0° or 90°) and the **mirror-tied chiral pair** (both ±θ partners at the same c, so the probe is M·T-even and immune to s21's chirality). S1×T1 contributes only its tied ±30° pair, since ⊥ is B's own line.
- c = ±0.05 per class entry.
- Read: odd part (R₊ − R₋)/2 and even part, relative to B's s21 value (1.369; base replicate included). Then line searches along positive odd parts, and a small bounded joint search (≤ 4 classes, |c| ≤ 0.2 on top of B, campaign box) with min(s21, r46) as the target.

**Prediction to falsify (from swarm-p's bookkeeping and swarm-c's sign rule):** at B the classes whose guiding-centre images G ± G_R land on w3 shells (|G|² = 4, 12, 16) should carry the odd parts. Specifically |G|²=3 × T1 θ = 0 (both images on |G|² = 4, w3 +3/5) should gain at c > 0. Most others should be concave and below B, as at the parent.

**Expected sign of R − R_B:** mostly negative; ≤ 3 classes with positive odd part. **Budget:** 35 now + ≤ 60 follow-up. Caveat (swarm-f): |R|² = 3 is two-valued on s21 and |R|² = 4 is aliased on r46. No T3/T4 ranking from s21 alone; the free r46/r56 stages decide.
