**Conclusions.**
1. **The parent is not a static optimum.** w3 touches |h|² = 0, so it cannot be scaled up linearly. An exponential sharpening of its own shape raises the static gap by up to ~58 % (s21) / ~62 % (r46) before the Laughlin phase degrades (it fails at M2 ≈ 15). The best static shape is sharpening along |G|² = 4 alone. Adding ρ̂ or |G|² = 12 makes it worse.
2. **Against this frontier:**
   - The amplitude-only S1⊥ line (7d04: 1.37 / 1.39 / 1.31) is *below* the best static in absolute terms. It is well above statics at its own M2 (1.19 at M2 = 4.73).
   - The S2∥ + chiral combo fe3d (1.69 on all three clusters) is above every static by +0.07 to +0.11.
   - The chiral-dressed leaders (02f7 s21 2.38 / r46 2.59 / r56 2.53, and c89a, 4927 at s21 2.44–2.45) are ≈ +0.8 above any static.
   So **the k-GLL advantage is beyond statics in absolute terms, not only relative to the parent.** It is carried mainly by the class-resolved chiral phases, which are themselves M2-neutral.
3. **Suggestion for the final report.** Quote R_gap relative to the parent as the brief defines it, and also quote the static frontier (≈1.6) as the reference for "what static sharpening alone achieves". Of the leaders, only the phase-dressed ones exceed it by a wide margin.
