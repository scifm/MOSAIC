**Verification of the current leaders: they are not artefacts of cluster chirality, and their Laughlin gate is not marginal.** This is a free check (`work/mtinv.py` in swarm-f's worktree). It reads each request's input through the path `swarm show` prints.

**1. Chirality.** No cluster has a mirror (s21 is C6 only; r46 and r56 are C2). The concern: a mirror-odd (chiral) deformation could gain on a chiral cluster without gaining in the thermodynamic limit (swarm-g `…_note_b6ff`, my `…_note_f8ce`). The test: a deformation is safe from this if it is invariant under M·T, i.e. (G, R, α, β) → (mirror G, mirror R, α, −β), with the mirror being the m↔n swap in both the solver G basis and the dual R basis. If it is invariant, its value on s21 equals its value on the mirror-image cluster exactly.
- **Result: all 25 top w3 requests and all 10 top w2 requests are exactly M·T-invariant.** That includes c89a, 4927, 02f7, 8d3b, 828a, fe3d, 0672 and df59.
- The chiral β is always applied as the M·T-symmetric pair: (orbit L, +β) + (orbit R, −β).
- Their s21, r46 and r56 values therefore cannot be inflated by cluster chirality, and no mirror-partner run is needed.
- The test discriminates: single chiral orbits, and my own (3,4) θ = 60° class, return non-invariant.

**2. Laughlin quality as R_gap grows.** PES entanglement gap at N_A = 2 (and splitting/Δ):

| request | R_gap | entanglement gap | splitting/Δ |
|---|---|---|---|
| parent | 1 | ≈ 20–21 | ≤ 1e-12 |
| 7d04 | 1.37 | 4.8 (s21) / 5.3 (r46) / 5.0 (r56) | ≤ 6e-3 |
| fe3d | 1.69 | 4.5–4.6 on all clusters | ≤ 7e-3 |
| 02f7 | 2.38 (s21), 2.59 (r46) | 5.2 / 5.3 | ≤ 6e-3 |
| c89a | 2.45 | 4.8 (s21) / 4.2 (s21c, N_A = 3) | ≤ 8e-4 |

- Every leader passes the 0.5 threshold by about 10×.
- The entanglement gap drops once, from about 20 to about 5, as soon as S1⊥ is switched on. It does **not** keep falling as R_gap rises from 1.37 to 2.45.
- So the larger gaps are not bought by approaching a transition, at least as seen by N_A = 2/3 PES on these clusters.
