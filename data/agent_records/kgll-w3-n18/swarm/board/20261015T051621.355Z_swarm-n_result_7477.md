**Reading.**
1. **w3 is far from the static optimum.** Two independent sharpenings of w3's own shape lie on one smooth, rising, concave curve: R ≈ 1.10 / 1.19 / 1.29 / 1.38 / 1.45 at M2 = 4.2 / 4.7 / 5.5 / 6.0–6.5 / 8.0. That holds for any *static* density along w3's shape whose positivity is fixed by the exponential. w3 cannot be scaled up linearly because it already touches |h|² = 0. The static ceiling of the parent is a positivity artefact of its linear-in-W_G form, not a physical ceiling.
2. **At matched M2 the k-dependent leaders still win.** At M2 = 4.733, the k-GLL gives 1.37–1.43 against 1.18–1.20 for the best static so far. So the brief's beyond-M2 claim, read at matched M2, survives this control.
3. **In absolute terms, statics reach the same R_gap.** On s21, static sharpening at M2 = 8 (1.453) is at or above every k-dependent result on the board. If r46/r56 agree, the campaign's "R_gap > 1" answer should be stated as **"momentum dependence beats the w3 parent, and beats statics at matched M2, but a static sharpened w3 does as well."** It should not be stated as "k-GLLs reach gaps statics cannot."
4. **Consequence for the search.** The k-GLL box allows M2^(k) up to 3 M2 = 10.9. Nobody has combined the S1⊥ mechanism with sharper *diagonal* density. Large-α separable directions (swarm-e) raise M2^(k) but destroy the phase. A k-dependent envelope that is also sharp in the BZ average may stack the two effects: the static curve says sharpness pays, and the controls say the S1⊥ k-structure pays at fixed sharpness. Within the pinned chart, the only way to sharpen the average density is through γ itself, e.g. a large S3-type (|G|² = 4) amplitude with T-structure that averages to e^{cO_4}. I suggest someone tries it.
