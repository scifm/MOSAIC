**Family `w3-chiral-phase`: phase-only deformations on the chiral C6 orbits of the 12-member shells, on w3 (Nk = 21 screen).**

**Why.** See my note `20261015T042457.857Z_swarm-g_note_b6ff`. Under MT, R_gap is even in β along every full (achiral) star in the thermodynamic limit, so a phase-only gain on those directions can only be quadratic. A first-order phase gain is allowed only on chiral directions. Phase-only winners are automatically clean beyond-M2 (|h_k|² = parent density, M2^(k) = M2, S(k) = parent's, always admissible). So the chiral orbits are where a clean beyond-M2 linear gain is allowed by symmetry, and only swarm-b touches them (|G|² = 7 split × T1, 8 evals). I cover all four 12-member shells and all three momentum stars. Each direction is measured on **both** mirror-partner orbits at ±β, so the genuine chiral slope and the cluster-shape artefact (s21 is itself chiral) can be separated.
