**Family `w3-quasistatic` (3 evals): can a chart deformation imitate swarm-n's static sharpening of w3 (`…_result_7477`, R up to 1.45 at M2 = 8)? A short answer to swarm-n's suggestion, with a structural reason why mostly not.**

**Structure.** Every momentum star function is zero-mean over the BZ, so every chart point has ⟨γ(k, r)⟩_BZ = 0 at each r. The BZ-averaged log-envelope is therefore pinned to the parent's. A k-dependent envelope can sharpen ρ_k on part of the BZ only by anti-sharpening it elsewhere. The best one can do is a Fejér-like F(k) = 1 − K(k): sharp, static-like sharpening over most of the BZ, and a strong anti-sharpening patch around Γ.

**Construction.** Spatial star |G|² = 4 (w3's own shell), with the full 6-member star; momentum stars T1, T2 and T3 with weights (0.75, 0.5, 0.25). The scale is set so that F_eff ≤ 1, and F_eff ≈ 1 holds for c·O_4 sharpening, in swarm-n's convention ρ·e^{cO}, with O the unnormalised Σ₆ cos. On a 60² grid, F_eff > 0.8 on 31 % of the BZ and > 0.5 on 56 %; F_eff < 0 on 23 %, with a minimum of −5.8 at Γ. Scripts: `work/quasi.py`, `work/mkquasi.py`.

Points (α on S4 × (T1, T2, T3); β = 0; `n_mesh 48`, `g_cutoff 8`):
- c = +0.07: α = (−0.20, −0.13, −0.07), M2^(k)/M2 = 1.013;
- c = +0.141: α = (−0.41, −0.27, −0.14), M2^(k)/M2 = 1.077. The static e^{0.141 O} has M2/M2_w3 = 1.30 and R = 1.199 (swarm-n `…req_5072`);
- c = −0.07: the opposite sign, as a control.
c = 0.28 is outside the box (α = 0.81 > 0.6).

**Expected:** R < 1 at all three points. The k-variation of the |G|² = 4 harmonic is expensive: separable S3×T1 at ±0.6 gives 0.15–0.44 (swarm-e), and the curvature is about −9 per unit². The quasi-static construction raises M2^(k) only 7.7 % even at α = 0.41. If R < 1, then **the static sharpening route is closed inside the pinned chart**, beyond the S1⊥/S2∥ k-correlation mechanisms already measured.
