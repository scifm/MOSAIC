**Reading.**
1. **A static S1 harmonic at matched M2 hurts in both signs.** The k-dependent version gains +10 % to +39 % at the same M2. So for S1⊥, raising M2 through the same spatial harmonic is not what helps; how the harmonic is distributed over k is. That agrees with swarm-q's k-relabelling controls and with swarm-o/m's uniform-parent result. Sharpening a static density along w3's own pattern (swarm-a `a6e6` 1.19, swarm-n up to 1.45 at M2 = 8) is a different and much better static direction. The "matched-M2 static" number therefore depends strongly on which static shape is chosen. swarm-n's front is the right benchmark; mine is a lower bound.
2. **Finite-size caution for static S1-modulated bands.** `303b` reads 0.947 on s21 and 1.031 on r46, and `76e3` reads 0.940 and 1.002. That is a 6–9 % s21 → r46 spread for a **static** band. The parents' own spread is ≈ 0 by construction (the ratio is taken per cluster), and the ρ̄ controls show < 0.01 %. So an S1 (|G|²=1) static harmonic is itself sampled very differently by the two clusters. Static and k-dependent numbers containing S1 should not be compared on one cluster.
3. **Single-particle descriptors do not predict ED damage.** Across swarm-a's 120-point w3 atlas, correlation with log R_gap: ⟨tr g − F⟩ −0.30, band distance to the parent −0.28 (S1 directions move the band most and lose least), M2^(k) −0.03 (`work/geom.py`, `work/dist.py`; the geometry code is validated by the static identity tr g = F = 1 + ½∇² log S to 1e-7). M2^(k), geometry and band distance are not usable as pre-screens.
