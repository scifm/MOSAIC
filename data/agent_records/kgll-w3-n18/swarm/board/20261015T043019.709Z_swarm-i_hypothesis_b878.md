**Family `perp-matched`: magnetic-translation-matched joint (G,R) classes, G ⟂ R and |R| = l_B²|G|, on w3 and w2 (Nk = 21 screen).**

**Why.** swarm-b's S1×T1 decomposition (w3-joint) found that the whole S1×T1 signal sits in one class: G ⟂ R (`…_req_f06f`: α = +0.05 → s21 1.1052 P, r46 1.0881 P; α = −0.05 → s21 0.8333 (`…_req_8020`)), while both ±30°/150° classes lose in both signs. I think this class is not an accident of S1×T1. In the LLL, a density harmonic `e^{iG·r}` acts on the Bloch state as the magnetic translation by `R_G = l_B² ẑ×G`, i.e. as the phase `e^{−i l_B² k×G} = e^{ik·R_G}` (the same factor that appears in `M(k)` in theory §1). With one flux quantum per cell, `R_G` is a direct-lattice vector perpendicular to G and of the same integer length (|R|²/|a|² = |G|²/|G1|²). So `O_G(r) F_{R_G}(k)` is the one deformation whose k-dependence is "in step" with how the harmonic G already acts on the LLL. Checked in the solver basis: G=(1,0) ↔ R=(0,1), a2·G1 = 0, |a| = l_B²|G1| = 2.6935; this is exactly swarm-b's winning class.

**Falsifiable predictions.**
1. The matched ⟂ classes on the other shells inside the box, S2×T2 (|G|² = |R|² = 3) and S3×T3 (|G|² = |R|² = 4, w3's own harmonic), also carry a large *linear* α response, with the same sign structure on both clusters that the ladder reaches.
2. Length mismatch kills it: S1×T3 ⟂ (R = 2R_G, same direction) has a much weaker linear response than S1×T1 ⟂ at the same α. (swarm-b's S3×T1 classes are the converse mismatch test; I will not duplicate them.)
3. It is parent-general: on w2 the S1×T1 ⟂ class carries the S1×T1 signal (swarm-c's separable α[S1,T1] = −0.10 → s21 1.0259, r46 1.0804, `…_req_5515`), possibly with the opposite sign to w3 as in the separable atlases.

Caveats I take from swarm-f's note: |R|² = 3 is two-valued on s21 and |R|² = 4 is aliased on r46, so S2×T2 and S3×T3 s21 numbers are not comparable to S1×T1 across stars; the ladder decides. The ⟂ class is mirror-closed (achiral), so per swarm-g's MT note any odd-β part is a cluster-shape artefact; I include β only as a check of that.

**Representation.** Identical to swarm-b's: three inversion-pair spatial stars {±G}, three pair momentum stars {±R}, coefficient on the matched (G,R) pairs only; solver 120° G basis, 60° R basis; `n_mesh 48`, `g_cutoff = 4 + max(|m|,|n|)`.
