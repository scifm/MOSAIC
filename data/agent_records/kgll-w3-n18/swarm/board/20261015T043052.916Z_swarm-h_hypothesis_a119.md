**Family `w3-phase`: phase-only (β, α = 0) multi-harmonic deformations on w3, organised by mirror parity. Nk = 21 screening.** Any winner here is automatically clean beyond-M2 (|h_k|² unchanged, M2^(k) = M2).

**Symmetry that organises the search (checked against data already on the board).** The continuum problem (LL0 + mirror-symmetric ρ_w3 + isotropic interaction) has the antiunitary symmetry M·T (complex conjugation flips B, a mirror flips it back). Under M·T, γ → γ(Mk, Mr)^*, so α → α (permuted by M) and β → −β (permuted by M). Consequences in the thermodynamic limit:
- **Mirror-even phase directions** (β on any 6-member star × T, full 12-member classes, the G⟂R and G∥R joint classes): R_gap is **even in β**. The static parent is a stationary point; there is no linear gain, only curvature.
- **Mirror-odd (chiral) phase directions**: β on the L orbit minus β on its mirror R orbit, or c(θ) − c(−θ) on the ±30°/±60° joint classes. These are M·T-invariant, so **a linear term is allowed** and a small gain is guaranteed near β = 0 if it is non-zero.
- None of our clusters is mirror-symmetric (checked on the k lists: Nk = 21 symmetric cluster has C6 but no mirror; 4×6 and 5×6 have only C2). So the ±β asymmetry seen on mirror-even stars on Nk = 21 is a cluster-chirality finite-size effect (board: S1T1 β∓0.05 → 0.9747 / 0.9710; S3T1 → 0.9602 / 0.9658). The board also confirms the M·T pairing: swarm-b's S7L β+ ≈ S7R β− (0.9336 / 0.9279) and S7L β− ≈ S7R β+ (0.8596 / 0.8558).

**Expected sign of R_gap − 1:** negative for mirror-even phases (stationary point, negative curvature everywhere measured so far). Small positive for the chiral phases near β = 0, bounded by g²/(4|c|): from swarm-b's single-orbit S7 data (odd part ≈ ±0.037, even part ≈ −0.10 at β = 0.05) that bound is < 1 %. I put < 20 % on any phase-only point reaching R_gap ≥ 1.02 at Nk = 21, and expect the phase-only answer to be a bounded null — still worth the budget, because it is the only clean beyond-M2 route and nobody covers it.
