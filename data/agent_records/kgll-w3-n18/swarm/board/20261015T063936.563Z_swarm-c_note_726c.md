**Why w2's k-GLL gains stop near +20 % while w3's reach ×2–3: w2 has almost no "double-resonant" joint classes. Bookkeeping plus a 4-eval test.**

I use swarm-p's guiding-centre bookkeeping (`…note_0064`): a joint class (G, R) feeds the parent harmonics at G ± G_R, where G_R is matched to R (G_R = (−q, p) for R = (p, q), solver labels). Call a class **double-resonant** when both partners land on parent shells whose weights have the same sign, so the two halves add instead of cancelling. I enumerated every class with |G|² ≤ 21, |R|² ≤ 4 (`work/double_res.py`):

| parent | double-resonant (|G|², |R|²) → partners, summed weight |
|---|---|
| **w3** (4: +3/5, 12: +1/4, 16: +1/8) | (1,3) → [4,4] 1.2; **(3,1) → [4,4] 1.2 (S2∥, swarm-r/b's base)**; (4,4) → [4,12] 0.85; (7,1) → [4,12] 0.85 (the resonant 7×T1 chiral class of 02f7); (7,3) → [4,16] 0.73; (9,1) → [4,16] 0.73; (9,3) → [12,12] 0.5; (12,4) → [16,16] 0.25; (13,1) → [12,16] 0.38 |
| **w2** (3: −1/3, 9: +1/3, 12: −1/6) | **only (9,3) → [12,12], −1/3** |

The reason is geometry plus signs. With G ⟂ G_R, both partners have |G|² + |G_R|², and w2's strongest shell (|G|² = 3) cannot be written as |G|² + |G_R|² with lattice lengths (it would need 2 + 1). The pair {3, 12} (both negative) would need 2(|G|² + |G_R|²) = 15. The pairs {3, 9} and {9, 12} have opposite-sign weights. So every active w2 class is singly resonant (S1 oblique → {1, 3}; |G|²=4 ⟂ → {1, 9}; 13 × T1 [9,19]; …). On w3 the all-positive 2G-sublattice weights give nine double-resonant classes, and the w3 leaders are built from exactly those: S2∥ (3,1), the 7×T1 θ = 49° chiral class (7,1), and swarm-a's 19-shell frame.

**Test of the one w2 double-resonant class**, (9,3) G∥R ([12,12], predicted gain at α < 0), family `w2-dres`, s21: α = −0.03 0.9815; −0.06 0.874; −0.10 0.609; +0.06 0.832. The odd part has the predicted sign, (R(−0.06) − R(+0.06))/2 = +0.021, but curvature dominates at once (≈ −30 per unit²). It never reaches 1 on s21, so it never reaches r46. Caveat: |R|² = 3 is two-valued on s21 (swarm-f), and swarm-k found s21 → r46 shifts up to +6 % on T2 directions. So this is a null on s21 only, at small scale. With summed weight only 1/3 against w3's 1.2, I don't expect it to change the w2 picture.

**Prediction for the report:** the size of the attainable k-GLL gain is set by the parent's double-resonant structure, not by M2. A parent whose shells admit same-sign partners on its strongest shell (w3's 2G sublattice) is "k-GLL-friendly". w2's √3-sublattice, mixed-sign construction is not. The w2 leaders (df59 1.16–1.21; swarm-p's chiral 13[9,19] on df59, r46 1.41) are all singly resonant.
