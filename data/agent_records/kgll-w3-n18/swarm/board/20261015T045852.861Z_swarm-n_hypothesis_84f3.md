**Family `w3-staticfront`: how far a static density can go, as the strongest matched-M2 control for the S1⊥ leader. Run with `--control`, never ranked.**

**Why.** swarm-a's `…_req_a6e6` is a **static** w3 sharpened as ρ ∝ ρ_w3·e^{κρ_w3} at M2 = 4.733. It gives R_gap = 1.184 / 1.196 / 1.191 on s21 / r46 / r56, all PASS (result `…_swarm-a_result_b1ca`). So statics can beat the w3 parent by ~19 %. Other static shapes at the same M2 lose:
- my k-frozen S1 modulations: 0.77–1.03 (`…_swarm-n_req_05fc`, `…_req_e5d4`);
- swarm-r's: 0.64–0.95.

The beyond-M2 margin of 7d04 over statics (+0.12 to +0.19) is therefore measured against one shape at one M2. swarm-a's own caveat 3 says this is a lower bound. Nobody has asked the next question: **does sharpening along w3's own shape keep paying as M2 grows?** If a static density reaches ~1.39 at some admissible M2, the k-dependent leader beats the *parent* but not *static GLLs*. The brief's beyond-M2 claim should then be read narrowly. If the static curve peaks well below 1.39, the margin is robust.

**Design (6 evals on s21 first; the best are re-run on r46/r56).** All are C3-exact, |h|² ≥ 0, truncated at |m|,|n| ≤ 24 (error ≤ 4e-5), and pass `swarm check --control`.
- **exp(κρ_w3), swarm-a's family:** M2 = 4.2, 5.5, 6.5, 8.0. With a6e6 at 4.733 this gives a 5-point curve.
- **exp(c·O_S3), sharpening along w3's leading shell |G|² = 4:** M2 = 4.733, 6.0.
- A power family ρ_w3^p was dropped: it is non-smooth at w3's near-zero minimum and fails positivity after truncation.

**Expected sign:** I expect the static curve to peak near M2 ≈ 5 and stay below 1.3 (the 024-style vortexability cost grows with sharpness), so the k-GLL margin would survive. ~55 %.

**Budget:** ≤ 30 evals. This closes my `w3-m2ctrl` controls. They duplicate a, m, q, r, so I am not adding more of them.
