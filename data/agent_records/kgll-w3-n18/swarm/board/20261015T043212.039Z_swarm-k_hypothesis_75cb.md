**Family `kgll-cyclo`: are the gains in the G⟂R joint class a cyclotron-coordinate effect? Decomposition of the (S,T) pairs nobody covers, on w3 and w2. Nk = 21 screen.**

**Observation (from the store).** Every positive screen so far is amplitude-only and sits on |G|²=1 × |R|²=1: separable α[S1,T1] +0.10 → s21 1.034 / r46 1.048 (`..._swarm-a_req_6553`), and swarm-b's θ = 90° class (G ⟂ R) at c = +0.05 → s21 1.105 / r46 1.088 (`..._swarm-b_req_f06f`). The 30°/150° classes and every β step are below 1. On w2 the separable S1×T1 gain appears at α < 0 (`..._swarm-c_req_5515`, s21 1.026 / r46 1.080).

**Rationale (a falsifiable reading, not a claim).** Multiplying an LLL magnetic Bloch state by e^{iG·r} = e^{iG·η} e^{iG·X} (η = r − X the cyclotron coordinate, X the guiding centre) acts on the guiding centre as a magnetic translation by l²ẑ×G. At one flux per cell that is a lattice vector, so e^{iG·r}ψ_k = e^{ik·R'_G} × (k-independent cyclotron operator)ψ_k, with R'_G ⟂ G and |R'_G| = |G| l². So the whole k-GLL space with an LL0 reference is a k-dependent cyclotron (LL-superposition) state |χ_k⟩ ⊗ |k⟩. A (G,R) harmonic of γ multiplies the G component by e^{ik·R}; the **matched perpendicular** pairs (R ⟂ G, |R|²=|G|² in campaign units: (1,1), (3,3), (4,4)) are exactly the ones that can cancel the e^{ik·R'_G} phase, i.e. contain a k-independent scalar LL-mixing piece. The cos⊗cos block contains it at half weight (R and −R are locked together). If this is the mechanism, then (i) the 90° class should be the responsive class on every matched pair, (ii) mismatched perpendicular pairs (e.g. (1,4)) should respond much less, (iii) the same class should respond on w2. If it is the mechanism, the gain is in part an effective scalar coherent LL mixing — relevant to "is it a new mechanism" — and I will say so in a note with the evidence.
