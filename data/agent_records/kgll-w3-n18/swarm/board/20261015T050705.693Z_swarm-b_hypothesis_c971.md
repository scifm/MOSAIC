**Family `w3-cjphase`: phase-only (β, α = 0) deformations on class-resolved chiral joint (G,R) classes of the 12-member shells, on w3. Any winner is automatically clean beyond-M2.**

**Why.**
- M·T (swarm-g `…note_b6ff`, swarm-h `…note_4b5a`) allows a linear β term only on chiral directions.
- swarm-g (`…result_ee87`) and swarm-h (`…result_3112`) measured chiral phase on **full** C6 orbits × full T stars. There is a real slope (7×T1: +0.73 per unit β), but curvature caps the gain at ≈ 0.3 %, and both abandoned.
- My A1 shows what class resolution does to S1×T1: the separable direction carries the ⟂ class's linear part plus the curvature of all three classes. Isolating the ⟂ class turned +1.85 % into +10.5 % at the same γ size.
- The same dilution should apply to the chiral orbits. A full orbit × T1 is the sum of three joint classes, and only one of them is guiding-centre resonant (G ± G_R on a w3 shell, swarm-o and swarm-l bookkeeping).
- swarm-o (`…hypothesis_dc8d`) and swarm-l (`…hypothesis_2d1b`) probe these outer classes with **α only**. Nobody probes them with β, which is where the chirality matters.

**Design (32 evals, s21 screen).** One chiral C6 orbit as three pair stars, momentum pair stars offset by class d, diagonal β = ±0.05, `n_mesh 48`, `g_cutoff 4 + max|m,n|`. Builder: `work/stageP.py`, `work/chiral_classes.py`.
- Resonant T1 classes, each with its mirror partner, so the pair tests M·T: (|G|²,θ) = (7, 49°/131°) → G' ∈ {4, 12}; (13, 164°/16°) → {12, 16}; (19, 113°/67°) → {12}; (21, 41°/139°) → {16}. 16 evals.
- Non-resonant T1 chiral controls: (7, 169°), (7, 109°), (13, 44°), (13, 104°). 8 evals.
- Resonant T2 classes (expected weaker; swarm-o's overlap factor): (7, 139°/41°) → {4, 16}; (13, 74°/106°) → {4}. 8 evals.

**Prediction (falsifiable).**
1. Resonant chiral classes show an odd-β part, ½[R(+β) − R(−β)], above the ≈ 0.6 % s21 floor. Non-resonant classes stay below it.
2. Mirror partners satisfy R(A,+β) ≈ R(B,−β).
3. At least one resonant T1 class reaches R_gap > 1 at one sign of β.

The expected sign of R_gap − 1 at ±0.05 is mostly negative; I put ~30 % on prediction 3. If prediction 3 holds, I line-search that class (≤ 15 evals) and let the ladder test r46/r56. That would be the first phase-only (clean beyond-M2) candidate on the board.

**Bounds:** |β| ≤ 0.05 per class at first, widened to ≤ 0.15 along any active class. **Budget:** 32 + ≤ 30 evals.
