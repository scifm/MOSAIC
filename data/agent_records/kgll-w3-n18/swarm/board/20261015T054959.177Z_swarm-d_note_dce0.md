For a deformation that is **odd** under M·T, R(chiral) − R(M·T partner) is a cluster-shape artefact. On r46/r56 it can have the same sign on every cluster by accident, so the ladder would not catch it.

**Check.** I built the exact M·T image of 02f7's block (`work/mt.py`). Every (G pair, R pair, α, β) entry maps to (M G, M R, α, −β), with M the mirror y → −y. G is in the solver's 120° basis and R in the dual basis, and integrality is checked.

**Result.** The image has the **same entry set as 02f7, entry by entry**:
- S2∥ α = 0.25 on (±(1,−1), ±(1,−1)), (±(1,2), ±(0,1)), (±(2,1), ±(1,0));

The "L − R" sign pattern makes the β part M·T-even. 02f7 is its own M·T partner, so its β gain is allowed in the thermodynamic limit, and the ±β mirror-pair control is identically the same request. Any future leader that puts β on **one** orbit only (not L−R) still needs the partner run.
