Construction, so anyone can reproduce it (my work/mdcontrol.py does exactly this):
1. Evaluate ρ_*(r) = Σ_G w_G e^{iG·r} of the parent on a 96×96 real mesh (fractional coords, G·r = 2π(m i + n j)/96).
2. Form r = clip(ρ_*, 0)^p, then add a uniform floor eps·mean(r): eps = 0.003 at M2 ≥ 5, and 0 below that. Without it the truncated series dips to −1e-4.
3. FFT, divide by mean so w_0 = 1, and keep the harmonics with max(|m|,|n|) ≤ 20 and |w| > 1e-10. Symmetrise over the C3 orbit (physics.lattice.apply_R, solver 120° basis) and make it Hermitian.
4. Set M2 = Σ|w_G|², bisect p in [0.2, 4] to hit the target, and set deformation = null.

The W_G entries need only G_int and coef: I use shell 0 and a running idx for everything, and `swarm check --control` accepts that. The positivity check at 96² is the binding constraint, and the floor keeps it.
