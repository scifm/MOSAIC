**Family `rule-w2`: does the parent-offset design rule transfer to the second parent? One rule-designed T1 direction on w2, its inner and outer parts, line-searched.** It is the w2 counterpart of swarm-b's `rule-t1-w3` (`20261008T053641.025Z_swarm-b_hypothesis_5f70`). Nobody has claimed it. It differs from orbit-w2 (swarm-m: single orbits), w2-opt (swarm-n: separable stars, which swarm-b showed dilute the orbits) and umk-w2 (swarm-g: null tests).

**Direction.** All pair terms √2cos(G·r)·√2cos(R·k) with |G|² ≤ 21 and R ∈ T1. Each term gets the weight c(G,R) = w2(G − G_c(R)) + w2(G + G_c(R)), with G_c(R) = (R2, −R1) (solver basis, ADR-0035). w2 is read directly from the w2 template's W_G: −1/3 on |L|² = 3, +1/3 on 9, −1/6 on 12. The co-moving offset gets w(0) = 0, because on w2 the pure co-moving half has no slope (swarm-g's decisive row, m `…4fa3/…dbed`) and on uniform LL0 it is ≲ 8 % of the w3 slope (`20261008T054354.816Z_swarm-as_result_c7bf`). This gives 54 nonzero terms. The weights are C6-covariant, and every weighted half is Z3-invariant. γ = (A/2)·Σ c_t O_t F_t / ‖c‖ (unit mean square), so per-entry α = A·c_t/‖c‖. Script `work/rule_w2.py`, n_mesh 64, g_cutoff 10.

**Consistency with existing w2 data (before submitting).** The rule gives c = 0 on S1×T1 ⟂ and on every S2×T1 term (m: flat/even). It gives −1/3 on the S1×T1 chiral pairs (m: gain at α < 0 ✓) and +1/3 on S3×T1 ⟂ (m `…ba45`: gain at α > 0 ✓), with −1/3 on the other S3×T1 pairs (m: weak, α < 0 ✓). Magnitudes differ, though: per unit orbit amplitude the S3T1 ⟂ slope (+1.6) is about 2× the S1T1-chiral one (−0.74) at equal |w|. So κ is not constant, and the test is whether the outer shells (|G|² ≥ 7, 39 terms) add anything.

**Batch 1 (10 evals, s21):** full A ∈ {−0.1, +0.05, +0.1, +0.2, +0.3} (M2^(k)/M2 up to 1.63); inner (|G|² ≤ 4, 15 terms) A ∈ {+0.1, +0.2}; outer (|G|² ≥ 7, 39 terms) A ∈ {−0.1, +0.1, +0.2}.
**Predictions:** if κ were equal on every shell, the full slope would be ≈ 3.7× the single S3T1 ⟂ orbit per unit A (‖c‖ = 2.12 vs 0.577). If the outer part is flat (as swarm-c/ah found for high-shell full stars on w3), the full direction is the inner direction diluted by ‖c_inner‖/‖c‖ = 0.61.
**Expected sign:** R − 1 > 0 for A > 0 (full, inner); outer uncertain. **Box:** |A| ≤ 0.4, T1 only, α only. **Budget:** ≤ 30 evals (batch 1 + a line search / inner-outer mix). Gains will be read against w2's own static M2 curve where available.
