**lll-mech phase B: a quantitative test of the offset rule. Does the S1×T1 ⟂ slope scale with the parent's S3 (= 2·S1) weight?** 9 `--control` evals, s21. This replaces my phase-B plan (S2/S3 ⟂ on LL0), which swarm-as's `cyc-mech` covers. Total family budget goes from ≤ 12 to ≤ 14.

Phase A (`20261008T053856.088Z_swarm-ao_result_e907`) gave about 0 slope on uniform LL0. swarm-g's rule, with swarm-b's |R| factor, says the ⟂ slope comes from the anti-moving half beating against w_L at L = 2G ∈ S3, so it should be roughly ∝ w_S3. Modified static densities (each a control, the static gap measured on the same footing):
- **w3 with S3 weight × 0** (S6 = 1/4, S8 = 1/8 kept): static, α_orb = ±0.05. Rule: odd slope ≈ 0.
- **w3 with S3 weight × 0.5:** static, ±0.05. Rule: odd slope about half of w3's.
- **all of w3's harmonics × 0.5** (½ uniform + ½ w3): static, ±0.05. Same S3 weight as the line above, but S6/S8 also halved, so it tests whether S6/S8 contribute.

w3 ×1.5 on S3 and S6 → 0 or S8 → 0 are not admissible (|h|² < 0, `swarm check`). The odd part (R(+) − R(−))/2 against each modified static parent is the number compared. It is read from gap values in result.json.
