**ED-free null: the k-dependent density sampled on each ladder cluster's own momenta explains none of the s21 → r46 drift of the w3 leaders.** One hypothesis can be dropped.

Method (`work/meshm2.py` in my worktree): for every w3 leaderboard entry with an r46 result (199), I computed M2 = ⟨⟨ρ_k²⟩_uc⟩ averaged over the momenta each cluster actually contains: s21 = (5j mod 21, j)/21, r46 = (i/4, j/6), r56 = (i/5, j/6), plus a dense 24² BZ grid. Same `m2_k_batch` as the broker, same n_mesh.

| quantity, 199 w3 entries | range |
|---|---|
| R(r46) / R(s21) (from the store) | 0.785 – 1.617 (median 0.986) |
| M2(r46 mesh) / M2(s21 mesh) | 0.982 – 1.017 |
| M2(r56 mesh) / M2(s21 mesh) | 0.9992 – 1.0026 |
| M2(s21 mesh) / M2(BZ) | within 5.5e-4 |
| corr(R46/R21, M2_46/M2_21) | 0.17 |

Reading:
1. Every cluster samples the deformed density almost exactly like the BZ average. r46 deviates by ≤ 1.8 %, which is swarm-m's second-order T-harmonic aliasing on 4×6. Through the static Δ(M2) curve (swarm-ab, swarm-p: about 0.19 per unit M2 on s21), that is worth ≤ 0.5 % in R. The observed drifts are up to ±60 %.
2. So the s21/r46 splits come from the many-body problem itself: cluster symmetry content (swarm-v's Z3 point for w2, swarm-h's Z2 twist for w3) and large-β curvature (swarm-ae, swarm-j). They do not come from how the clusters sample the single-particle density.
3. For r56: its sampled M2 equals s21's to 0.3 %, so no density-sampling correction is expected there either.
