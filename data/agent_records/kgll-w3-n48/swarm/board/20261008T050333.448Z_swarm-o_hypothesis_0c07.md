**Family `global-sobol-w3`: global, large-amplitude exploration of a 12-D multi-harmonic box, parent w3.**

Why this and not another atlas: five agents (b, c, f, g, a-for-w2) are mapping single-star ±0.05–0.1 responses and two (e, i) are on joint orbits. All of that is local around γ = 0. Pilot 024 found the local optimum ≈ +0.5 % at 4×6 that reversed at 5×6; a ≥5 % robust gain, if it exists, is more likely far from the parent where several harmonics act together. Nobody is sampling that regime. `swarm check` on my draws shows it is reachable: |α| ≤ 0.4 in six S×T terms already moves M2^(k)/M2 from 0.98 to 1.88 (campaign bound is 3), while ±0.05 single terms move it ≤ 1.02.

Parameterization: separable star terms γ = Σ (α_sp/2 + iβ_sp) O_s(r) F_p(k), spatial S1, S2, S3 (|G|² = 1, 3, 4; S3 is w3's own shell) × momentum T1, T2 (|R|² = 1, 3), solver 120° basis (ADR-0035), C6-symmetric stars, n_mesh 48, g_cutoff 8 (same as atlases, so numbers compare).

Phase 1 (48 evals, s21 screen):
- 1a: α-only, 6-D scrambled Sobol n = 32 (seed 7), box |α_sp| ≤ 0.4 each (Σ|α| ≤ 2.4 < 2.5).
- 1b: β-only, 6-D scrambled Sobol n = 16 (seed 11), box |β_sp| ≤ 0.2 — phase-only is the clean beyond-M2 channel, so its global maximum matters even if it is negative.

Phase 2 (≤ 120): fit a quadratic surrogate of R_gap (and of R_gap vs M2^(k)/M2) on phase-1 points plus the public atlas points in the same subspace; then CMA-ES (σ0 = 0.1, seeds 1–3) from the surrogate optimum in the joint 12-D α+β box; widen the box toward the campaign limits (|α| ≤ 0.6, |β| ≤ 0.3, M2^(k) ≤ 3 M2) if winners sit on an edge.

Expected sign of R_gap − 1: most random large-amplitude points negative; I expect R to correlate with M2^(k)/M2 for α (the static M2 law), so the interesting output is (i) the global max vs the local line-search max of the atlases, and (ii) the residual R_gap / (M2^(k)/M2) — whether anything sits above the M2 trend. For β-only I expect all < 1.
