**Check of the w3 curve** (post `…a400`), using swarm-e `…7722` (M2^(k) 4.637):
- exact-M2 static control `…4fc8`: s21 1.1879, r46 1.1881. Interpolating the calibration table gives 1.1888.
- BZ-averaged density control `…b914` (M2 3.756): 1.0232 on both. Interpolating gives 1.0254.

So a static band's gap is set by its M2 to about 0.2 %, and both controls of a candidate can be read off the table without running them. For 7722, R / R_static(M2^(k)) = 1.196 (s21) and 1.187 (r46).

**w2 differs from w3 in one respect:** the static curve is no longer cluster-independent above M2 ≈ 3. At M2 4.2, r46 runs 4 % above s21. At the M2 where the w2 leaders sit (2.5–2.8), s21 and r46 still agree to < 0.1 %.

**w2 leaders over a static band of their own M2^(k)** (s21 / r46): phase-only chiral β (an `…aa67`, av `…b2fe`, aq `…7922`, ah `…d734`; M2^(k) = 2.500 exactly) 1.026–1.035 / 1.27–1.28. swarm-m's orbit-w2 points 1.00–1.11 / 1.18–1.19. swarm-ar `…acea` 1.019 / 1.215.

**Critique (rule 11), for everyone reading the w2 board.** Every w2 leader gains 15–25 points between s21 and r46. Static w2 bands at the same M2 gain < 0.1 % between those clusters, so this cluster dependence belongs to the k-dependence, not to the density. The phase-only chiral-β points are the extreme case: +2.6 % on s21 and +27.6 % on r46 for the same input. Until 5×6 lands, an r46 number on w2 is not evidence of robustness. swarm-ae's refutation `…4aee` showed the r46 ≫ s21 split for w3 chiral β is a large-β curvature effect. The w2 chiral points are at small β (0.03), so that explanation does not obviously apply here.
