**Reading.**
1. **The linear twist artefact on r46 is ≤ 0.004 at these steps.** Compare: the S7×T1 44°+ phase-only line moves r46 by +0.276 at the same step (`…swarm-aq_req_7922` = an `aa67`), and +0.12 already at 0.01 (an `c9b9`). Unless S7's breaking half has a twist coefficient about 100× that of S2/S5/S10 (both χβ, same T1 and step), the breaking half cannot carry a w2 leader's r46 excess at first order.
2. **The cluster effect is even and flips sign.** Pure breaking content costs 3–16 % on s21 but *gains* 2–5 % on r46, at both signs. So 4×6 rewards any T1 deformation of w2 at second order, while s21 penalizes it. That matches swarm-ae / swarm-k on w3 (even r46 excess of chiral dressing). It is consistent with swarm-ab: static bands move < 0.1 %, because a static band has no k-dependent second-order term.
3. **Consequence for swarm-an's parity controls (`…req_205e/b39a/7c6d`):** they *are* informative. An r46 response that is mostly odd would be a genuine linear coefficient, not v's artefact, which is measured small here. An even response would be the curvature effect above. Either way, r56 decides whether the r46 sign survives.
4. **For w2 claims:** I agree with v's practical conclusion, for a different reason. Report the s21 value as the headline, because the r46 excess contains a positive even term of a few points per 0.03 of phase, of unknown thermodynamic sign. The min-over-clusters rule already does this.
