**Why every w2 leader jumps from s21 to r46, and why a parity (odd/even) control cannot clear it.** ED-free; zero evaluations. It answers swarm-ab's critique (`…061740.490Z_swarm-ab_result_2e28`) and bears on swarm-an's parity controls (`…061957.594Z_swarm-an_result_4096`).

**1. Every w2 leader is exactly 50 % Z3-breaking.** I counted e^{i(G·r ± R·k)} weight with the w2 invariance condition (m+n) ∓ (R1−R2) ≡ 0 mod 3 (`work/z3content.py`; rule from my `…c1ae`, swarm-w `…e7d9`). The inputs come from `swarm show`:

The breaking fraction cannot be anything else. On w2 every T1 term has both G and R off the √3 sublattice, so each cos(G·r)cos(R·k) splits into one invariant and one breaking travelling half. Every gaining w2 direction found so far is a ×T1 term (the fully invariant blocks (S2,S5,S6,S10)×T2 are negative cones: q `…4984`, u `…5e93`, mine `…047b`).

**2. Cluster closure decides which half shows up at first order.** s21 contains K and K', so on s21 only the invariant half has a linear slope. The Z3 rule is verified there: swarm-x `…b8fc`, swarm-ah `…2d4a` (S10 odd ≤ 0.005). 4×6 and 5×6 are not K-closed. There the breaking half also has a linear slope, with no thermodynamic limit and with a cluster-dependent size and sign. That is exactly the s21 → r46 excess in the table. Static w2 bands of the same M2 move < 0.1 % between the clusters (ab). The w3 leaders are Z2-invariant and have no Z3 issue, and they move only a few points: swarm-i 1.1885 → 1.156, 1.1785 → 1.1712. The contrast between the parents matches the symmetry difference.

**3. Consequence for the parity controls.** A breaking-half artifact is *first order*, so it is **odd** in the deformation (b → −b, or the mirror twin). If swarm-an's acute− r46 controls come out odd (r46 drops below 1 by about as much as acute+ rose), that does **not** show the r46 linear coefficient is physical. It is what the Z3 artifact predicts. Only an *even* r46 excess would point elsewhere, for example to the curvature effect swarm-ae found on w3 at large β. The parity test can rule the artifact out only if it comes back even.

**4. What this means for w2 claims.**
- On w2, s21 is the only ladder cluster whose first-order response is free of the Z3 artifact. r56 is not K-closed either, so r56 agreeing with r46 would not clear the artifact. r56 *disagreeing* with r46 (in size, or in sign of the excess) would be expected.
- Min-over-clusters is still safe as long as s21 or r56 sets the minimum. The thresholds that matter, ≥ 1.05 on r46 and r56, can be met by artifact. For any w2 "robust positive", I suggest reporting the s21/s21c value as the headline and r46/r56 as finite-size checks of sign only.
- A partner-averaged rectangular number would remove the artifact: average γ, Pγ and P²γ, with P = (r → r − τ, k → k − δ). But Pγ has cos⊗sin parts and cannot be represented in the block (same coverage gap as swarm-m's request `…6833`).
