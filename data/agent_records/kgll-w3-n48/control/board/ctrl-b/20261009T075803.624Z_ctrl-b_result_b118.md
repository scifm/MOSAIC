Mechanism check (claim 2) for the w3-orient winners: matched-density static controls (--control, never ranked). Each control is the static GLL whose density is the BZ average of the candidate's normalised diagonal density, wbar_G = <W_G(k,k)/W_0(k,k)>_k on a 24x24 BZ grid, C6-symmetric, |h|^2 >= 0.

|---|---|---|---|---|---|
| 1c34 (S1d90 0.05) | 1.1178 / 1.1126 / 1.1068 | b15a | 1.0011 / 1.0010 / 1.0010 | 3.634 | 3.686 |
| 0937 (S1d90 0.20) | 1.4822 / 1.4056 / 1.4692 | 6347 | 1.0168 / 1.0168 / 1.0168 | 3.714 | 4.733 |
| 5153 (S2d0 0.20) | 1.3761 / 1.4072 / 1.4715 | fdbd | 1.0174 / 1.0175 / (running) | 3.734 | 4.553 |

The averaged density change accounts for about 0.1 % of the 11 % gain at c = 0.05, and about 1.7 % of the 40-47 % gain at c = 0.2. The controls' gaps scale with their own M2 (+2.3 % in M2 gives +1.7 % in gap, consistent with the static M2 picture). The candidates gain far more than their k-averaged M2 would buy: <M2(k)> rises 30 % for 0937 while its gap rises 39-48 %, and the static gap per unit M2 is sublinear (doc 46: Δ(w3)/Δ(w2) = 1.417 against M2 ratio 1.452). So neither the averaged density nor a scalar M2 explains the gain. Caveat, stated plainly: an M2-matched static control with M2 = <M2(k)> cannot be built by scaling w3 (|h|^2 < 0), so "beyond M2" here means beyond the k-averaged density. Whether some other static density with M2 of about 4.7 could do as well is not tested. Human: if you want a specific static control at that M2, say which.

Parent dependence: the same classes on w2 LOWER the gap (s21: S1d90 0.05/0.1/0.2 -> 0.982/0.960/0.884; S2d0 0.05/0.1 -> 0.939/0.754, 0.2 FAIL). The w2 class screen (all 6 classes, +-0.05) is running (b9).
