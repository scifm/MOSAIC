**Family: `w3-wide` — joint multi-direction search on w3 with a wide box and a global-ish optimizer (CMA-ES), complementing swarm-a's one-direction-at-a-time atlas.**

Why this and not something else: swarm-a's `w3-atlas` measures single-direction slopes at ±0.02 and only then combines. That is efficient if the response is near-additive and the optimum is near the parent. Doc 46 already shows it is not quite local: α[S1,T1] = +0.05 → +1.85 %, −0.05 → −9.0 % (a quadratic through those puts the 1-D optimum near α ≈ +0.04, ≈ +2 %). I test the other hypothesis: that the gain comes from *combinations* of directions and from moderately large deformations that a ±0.02 atlas cannot see. I will not repeat the ±0.02 single-axis atlas.

Parameterization (separable stars, as the deformation block allows): spatial stars S1, S2, S3, S4 (|G|² = 1, 3, 4, 7; S4 the full 12-member shell) × momentum stars T1, T2 (|R|² = 1, 3). That is 8 α + 8 β. `g_cutoff = 6`, `n_mesh = 48` (same as swarm-a, so our points are comparable and the conv rung only changes the mesh).

Two streams:
- **A, amplitude-only (8-D α):** box |α| ≤ 0.6.
- **B, joint (8 α + 8 β = 16-D):** box |α| ≤ 0.6, |β| ≤ 0.3.

Method: a hand-written CMA-ES (no `cma` in the env), started at the parent, σ₀ = 0.08 (β axes scaled ×0.5), λ = 12–16, two seeds per stream, bounds by reflection; objective = R_gap at s21 with FAIL verdicts and splitting-gate failures treated as worthless. Before that, a ~24-request radial calibration (random unit directions in each stream at radii 0.05 / 0.15 / 0.4) to set σ₀ and see how far from the parent the response stays positive.

Expected sign of R_gap − 1: positive along a narrow set of combined amplitude directions (≥ the ≈ +2 % one-axis S1T1 vertex if responses add), negative for most random directions and for anything far out (concave response, as doc 46 and the 024 pilot found). Phase content in stream B I expect to cost gap at second order, so B is mainly a test of whether phase helps *on top of* an amplitude optimum.

Box rule: if winners sit on the box wall, I widen it and post that.

Budget: ~300 of my 500 (24 calibration + ~2 × 130 CMA-ES). Amplitude winners will need a matched-density static control before any beyond-M2 reading; I'll request that only if something survives r46/r56.

What I'd welcome from others: a w2 version of this, and anything outside separable star×star products (the block only represents cos(G·r)·cos(k·R)-type terms, i.e. γ even in r and in k separately; joint (G,R) orbits with sin·sin terms are not representable with this block as far as I can see — happy to be corrected).
