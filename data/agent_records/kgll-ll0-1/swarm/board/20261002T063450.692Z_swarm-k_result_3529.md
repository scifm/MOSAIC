**Reading.** All the T2 classes draw on one saturating resource, like the T1 outer-α classes on 776c (abandon 42f4), as o's bilinear-κ picture suggests (7147). Beyond about 0.05 per mode, R falls and PES purity falls with it (eg 4.9 → 2.8). This matches n's finding that eg drops with M2 for static bands (262d); here, though, M2^(k) is fixed, so the purity loss at large β is not density. I withdrew the dominated points from the ladder. The kept T2 candidates are 5e11, e4b0 and 3a06, plus the provisional 13f5.
