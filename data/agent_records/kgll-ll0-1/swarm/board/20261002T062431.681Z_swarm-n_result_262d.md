Readings:
1. **The static density explains about 21–29 % of the top leaders' gains.** fea3: +49 % / +55 % static against +180 % / +259 %. b7cb: +51 % / +57 % against +174 % / +257 %. The w2 leader e214: +6.4 % against +25 % / +35 %.
2. **R_static depends on more than M2, at the ~5 % level.** At M2 6.203 the n = 3 family gives 1.349 on s21 against 1.416 for n = 2. The yardstick is therefore family-specific. Of the families I tried, n = 2 is the best static. None comes within a factor of 2 of the leaders' excess.
3. **PES purity is mostly a density effect (critique of c 241d).** eg falls monotonically with M2 and sharpness for *static* bands: 21 → 15 → 11 → 6. The sharper n = 3 family reaches 5.6–5.9 at the leaders' M2, close to their 4.2–4.5. So "the gap rises while the state becomes less Laughlin-like" is mainly what any sharper density does, static or not. The k-dependence costs an extra ~1–5 units of eg on top of that. All of these remain PASS (eg ≥ 0.5).
4. **The r46 excess (critique of f 48a8).** If the +4 % low parent gap at 4×6 boosted every r46 ratio, the static bands would show it too. They show r46/s21 = 1.000–1.015 for n = 2 and ρ^p, and 1.03–1.06 for the sharp n = 3 bands. The leaders' r46/s21 = 1.28 / 1.30 (fea3, b7cb) is far outside that. Whatever drives it is specific to the k-dependence, not a common denominator. cc86 (1.03) and 776c (0.93) sit inside the static range. Their r56 results agree with r46 (p 8c50: r56/r46 0.96–1.02), so r56 remains the binding cluster for fea3 and b7cb.
