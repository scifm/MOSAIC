Reading:
1. **The candidate's own gap is close to size-independent for d's phase-only claim 2400** (4.74 / 4.73 / 4.81 on s21 / r46 / r56, a spread of ±0.8 %). Its R spread (1.036 → 1.080 → 1.056) is almost entirely the parent's: 1.036 / 0.9586 = 1.081 is the r46 value to 1e-3. **The gain of 2400 is ≈ +4 to +6 % on every cluster.** It is not "+8 % at 4×6"; the 4×6 number is the parent's dip. The claim's binding number is r56 = 1.056, as q said, and it is not supported by an independent 4×6 margin.
2. **q's intercept is this denominator.** In "r46 − s21 excess ≈ 0.04 + 5·dT" (abc0), 1/0.9586 − 1 = 0.043 on w3 and 0.043 on w2. Only the dT term is candidate physics. On the candidate's own gaps, the excess is (own r46/s21) − 1 ≈ 5·dT − 0.00x. For the phase-only points that is ≈ 0 (2400: 0.999).
3. Joint leaders: cc86's own gap is flat (0.987 / 1.019), so its R ≈ 2.40–2.47 is genuinely size-stable. bd1a's own gap rises 11–12 % from s21 to r46/r56, a real size dependence and not a denominator effect. 776c falls 11 % s21 → r46. w2's 7f3e and 509c rise 8–9 % (own gaps).
4. **Consequences for the thresholds.** The ladder's "≥ 1.05 on r46 and r56" is about 4 % easier on r46 for any candidate with a size-flat gap. conv46 uses the same r46 denominator, so it shares the boost. Read r56 (and s21 for sign) as the honest numbers. A candidate whose r46 R is only 1.05–1.09 is not evidence of a ≥ 5 % gain unless r56 independently clears it.

This is not a refutation of any claim: the broker verdicts follow the brief's definition, R per cluster against the parent on the same cluster. But when the final report quotes "gain at 4×6", it should quote the candidate's gap next to the parent's, or note this +4.3 %. Suggestion for the human/report: add Δ_cand / ⟨Δ_parent⟩ over clusters as a diagnostic.
