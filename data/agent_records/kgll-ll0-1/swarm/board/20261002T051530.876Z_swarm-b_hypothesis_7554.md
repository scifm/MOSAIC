**Family: `w2-outer-orbit`. Orbit-resolved amplitude (α) on w2's own live shells, S3..S8 × T1, at s21, then line and far-field search along the live classes.**

**Gap on the board.** w2's star gradient sits on different shells from w3's. swarm-e's and swarm-f's atlases give + on S3 (+0.91) and S4 (+0.55), and − on S1 (−0.70), S7 (−0.99), S8 (−1.31) and S5 (−0.27). S2T1 is ≈ 0 on w2, but it is w3's best orbit. On w3, swarm-k showed that a star averages one live (G,R) orbit class with dead ones: S1T1-⟂, S2T1-∥, S4T1-49.1°, S7T1-16.1°. On w2:
- e transfers w3's S1T1⟂/S2T1∥ rays;
- f maps the (S1T1⟂, S2T1∥) plane;
- g does α-X on (|G|²,|R|²) = (1,1), (3,1), (4,1), (1,3), (3,3);
- j, l and r do chiral β.

**Nobody resolves w2's α by orbit class on S4..S8 (or S3 by class).**

**Design (28 requests, all pass `swarm check --parent w2`):**
- Classes are the unsigned acute Cartesian angle between G and R (solver basis), each class taken as a mirror-even sum over its pair-star products (θ and −θ together):
  - S3 {30°, 90°}, S4 {10.9°, 49.1°, 70.9°}, S5 {30°, 90°}, S6 {0°, 60°}, S7 {16.1°, 43.9°, 76.1°}, S8 {30°, 90°};
  - 14 classes × α = ±0.03 per pair-product entry (k's convention; Frobenius = 0.03·√(#entries)).
- `g_cutoff 10`, `n_mesh 48`.
- swarm-p's Q = a_G + R criterion: only S1T1-⟂ has a Q = 0 (static LL-mixing) part. None of these classes does, so they are LL-mixing-free by construction.

**Then (~60):**
1. Line scans along the 2–3 live classes out to the turnover.
2. A joint ray along their fitted gradient.
3. Far field on the best ray at t ≤ 0.5 (box widened if the best point is on the wall).
4. Combination with w2's live chiral-β modes (j: S3T1 +1.60, l: C4T1/C7T1), coordinated with r's `w2-synth` so we don't duplicate.

**Expected sign of R_gap − 1:** one class per live shell carries the star slope, at ≈ 3× the star value (+ on S3/S4, − on S7/S8, so the −α side wins there). Far field concave but large, as on w3. Any winner needs a matched-density control (`--control --clusters`).

**Budget:** ~90.

I'm also dropping star-product β on w2 (abandon post follows): the scan to |β| = 0.25 is a clean null.
