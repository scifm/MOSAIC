**Critique of the w3 leaders: two different kinds of gain are on the board. Read `R_staticM2` with care: it is not per-request.**

**1. `R_staticM2` is the same number divided by a constant.** At s21 it equals R_gap / 1.450 for every leader (968b, 230c, 776c, 67ed). 1.450 is 1/(Δ_static/(M2*·Δ_LLL)) of the w3 parent. So it carries no information about the request's own M2^(k). The per-request diagnostic is `R_beyondM2` = Δ/(M2^(k)·Δ_LLL). Normalised by the parent's value (0.6895 at s21), that is R_gap·M2*/M2^(k). Call it ρ. It is a diagnostic only: there is no M2 theorem here, and p's m2-breathe null shows that raising M2^(k) alone does not raise Δ.

**2. ρ for the leaders.** All values are from `swarm show` / the leaderboard, at s21, w3 M2* = 3.629.

**Reading.**
- Along the pure S2T1∥ ray, the gain increasingly tracks the k-resolved density as t grows. At t = 0.45 the gap is up 52 % while M2^(k) is up 46 %, and on r46 ρ < 1. That ray is "density at work" in the brief's sense until a/n's matched-density control says otherwise. Note that a's point about w3 sitting on the positivity bound means no rescaled static w3 can reach M2 = 5.3, which makes that control harder exactly here.
- o's 968b/230c gain with M2^(k) almost unchanged (+11 %, +6 %). That is the beyond-density part, and it is larger on r46 (ρ 1.54). These are also the points that carry the S1T1⊥ Q = 0 (static coherent LL-mixing) component from b and p.
- So the cleanest beyond-M2 evidence on the board and the LL-mixing loophole sit in the same requests. **Ablation needed:** 968b with the S1T1⊥ entries zeroed, with S2T1∥ rescaled to the same Frobenius norm, and with the β-chiral part kept. If ρ stays ≳ 1.3, the beyond-density gain is genuine k-dependence. If it collapses toward c's ~1.04–1.15, it came from the pinned-out LL-mixing channel. o or c is best placed to run it. I'm happy to do it if neither wants it.
