**Final matched-density control table: static density explains 10–30 % of every claimed gain except c 776c (54–70 %). Every density-control requirement in the brief's claim 2 is met on s21, r46 and r56 for the strong amplitude claims.**

**What a control is.** It is a static band, built from the parent pattern, whose envelope M2 equals the candidate's broker M2^(k), run with `--control` on the same clusters. The family:
- `mix2` / `mix3`: (1−s) ρ_* + s ρ_*ⁿ/⟨ρ_*ⁿ⟩, exactly positive with finite support (result fde8);
- `ρ*^p`: power-law, for small M2.

`mix3` runs about 5 % below `mix2` at equal M2, and n = 2 caps at M2 6.78. So the mix3 rows are a lower bound for parent-pattern static bands. swarm-a's averaged-density controls (20d3, all ≤ 1.047) are the other reading of "matched density".

"Share" = (R_ctrl − 1)/(R_cand − 1), the fraction of the gain a static band of the same M2 delivers. Values are s21 / r46 / r56.

**Conclusions:**
1. **Claim 2 (beyond M2) holds for every strong amplitude claim on all three clusters.** No static band at the candidate's M2 comes within a factor of 2.5 of its excess, with one exception: c 776c, where static density accounts for 54–70 %. The beyond-density remainder there is +0.17 / +0.12 / +0.21 in R. I suggest 776c be reported as "mostly density, residual beyond".
2. **At fixed density, the cross-momentum structure carries the gain.** The cleanest evidence is the bd1a/776c pair: β changes no |h_k|², yet R goes from 1.41 to 2.63 on r46. The static bands built from a candidate's own single-k densities (frozen slices) are *below* the parent.
3. **Static bands are size-stable; the candidates are not.** Static r46/s21 ≤ 1.015 for mix2 and ≤ 1.06 for mix3, and r56 sits between s21 and r46. So the candidates' cluster dependence is specific to the k-dependence (262d).
4. **The PES purity loss is mostly density.** Static eg falls 21 → 6 as M2 rises to 7.9 (262d).
5. **Scope caveat.** These are parent-*pattern* static bands. w2 and w3 are benchmark densities (doc 25, arXiv 2606.07323), not pure-LL0 static optima. Whether a *different* static pattern at the same M2 does better is the static-GLL search question, outside this brief.
