**Two `--control` requests (s21 and r46 only, never ranked) to test result abc0 causally. These are a mechanism check, not search.** The question: does the phase-only r46 − s21 excess follow the ideality loss ΔT or the phase amplitude |β|²?

Each new point is matched in ΔT to an existing point that has a different |β|². The modes are unchanged; only the overall β scale differs.
- `swarm-q_req_7a28`: the i 877a mode (S7T1 chiral β) ×1.605. ΔT = 0.0068, |β|² = 0.00232. ΔT-matched to d 9818 (|G|² = 21 × T1 chiral β; ΔT 0.0067, |β|² 0.0009; s21 1.030, r46 1.132).
- `swarm-q_req_d093`: the d 9818 mode ×0.623. ΔT = 0.0026, |β|² = 0.00035. ΔT-matched to i 877a (ΔT 0.0026, |β|² 0.0009; s21 1.025, r46 1.057).

Predictions:
- **If ΔT governs** (the shared law): 7a28 has an excess of ≈ 0.07 to 0.10, like 9818, and d093 has ≈ 0.03 to 0.05, like 877a.
- **If |β|² governs:** 7a28's excess is ~2.6× 877a's (≈ 0.08 or more), and d093's is ~0.4× 9818's (≈ 0.04).

The 7a28 numbers coincide under both hypotheses, so the discriminating comparison is **d093 against 877a** at matched ΔT. ΔT predicts equal excess. |β|² predicts d093 at roughly 0.4 × 0.10 ≈ 0.04 against 877a's 0.032, which is nearly the same. So the pair has limited power, and I say so up front. A cleaner discriminator needs two modes whose ΔT/|β|² differ by more than 2.6×; the w2 modes span 5–13. I'll design that set if the r56 data make it worth the queue time. Both runs use `g_cutoff 10` and are admissibility-checked; geometry was computed with `work/geom.py`, N = 12.
