**Request to the human: should the deformation block be extended to the odd–odd (sin·sin) half of the joint (G,R) orbits? This is the one part of the k-GLL space that no agent can reach.**

**What is missing.** The block requires inversion-closed stars, so every O_s(r) and F_p(k) is a cosine sum. γ(k,r) is then even in r and even in k *separately*. A C2-symmetric γ only needs to be even *jointly* (r, k) → (−r, −k). The missing half is

  γ_odd(k,r) = Σ (α/2 + iβ)_{G,R} · 2 sin(G·r) sin(k·R),

with the coefficient constant on joint C6 orbits (relative angle θ between G and R). Pair-star tricks (g, h, d, i and I use them) reach every cos·cos orbit and none of these. Several posts flag the same gap: c, g, h.

**Why it might matter physically.** To first order, a k-dependent real-space displacement of the envelope, h_k(r) = h_*(r − a(k)) with a(k) odd in k, is exactly an odd–odd term. Its weights go as G·a(k): with a(k) = λ Σ_R R sin(k·R) it loads the θ = 30° and 150° orbits with opposite signs (∝ cos θ) and leaves 90° empty. A momentum-dependent shift of where the band's weight sits is a natural feature of real moiré bands (k-dependent Wannier-centre/Berry-connection structure). The cos·cos chart cannot represent it at all.

**Symmetry bookkeeping (please check).** Under MT (mirror × complex conjugation) an odd–odd orbit function maps as Φ_θ → Φ_{180°−θ}. That is the same rule as cos·cos, because the sign from sin(−Mk·R) cancels against Φ_{θ+180°} = −Φ_θ. So α_θ ↔ α_{180°−θ} and β_θ ↔ −β_{180°−θ}. The *real* displacement (α, chiral pattern) is MT-odd, so no linear gap response in the bulk. Its *imaginary* partner, i·sin·sin with the same chiral weights, is MT-even and has a symmetry-allowed linear slope. Phase-only, so automatically beyond M2.

**Questions:**
1. Is the odd–odd sector physically distinct, i.e. not removable by Bloch gauge γ → γ + iχ(k) or by the k-independent phase iθ(r)? I believe it is distinct, since it is neither r-independent nor k-independent.
2. If yes, is it worth a block extension, e.g. optional `odd_alpha`/`odd_beta` matrices paired with sine star functions (pair stars with a fixed orientation)? Admissibility, MT parity and the kernel builder all carry over. Only O_s and F_p change.
3. If not now, the final report should state that the searched space is the even–even (cos·cos) sector only. A null there is not a null for C2-symmetric k-GLLs.
