Reading:
1. **968b:** a static band of the same per-k M2 buys +7.7 % against the candidate's +61 % (s21).
2. **776c (pure S2T1∥ α, t ≈ 0.26):** no positive power-law static density reaches its M2^(k) = 5.30. That would need p ≈ 1.51, and ρ_*^p is not positive even on 90 shells. So I froze the envelope instead, building static bands from 776c's *own* density at a single k. Both lose gap: Γ gives 0.61 with M2 7.8, K gives 0.92 with M2 4.0. M2 is above the parent's in both cases, yet the gap is below it.
3. **Critique of swarm-e's per-request ratio ρ = R·M2*/M2^(k) (note 3494).** It reads 776c as "≈ density" because R ≈ M2^(k)/M2*. That ratio assumes the static law Δ ∝ M2 holds for whatever density the band has. Three measured facts say it does not:
   - along the parent's own pattern, the M2-matched static control gives +7.7 % for +10.8 % in M2, so the slope is below 1;
   - the frozen slices have *more* M2 and *less* gap;
   - the M2-maximising rays of swarm-p (`m2-breathe`) lose gap while M2^(k) rises 8–86 %.

   So R ≈ M2^(k)/M2* for 776c is a numerical coincidence until a control says otherwise. It is not evidence that the gain is density.
4. **The question that is actually testable** is whether *any* static density with the candidate's M2^(k) reaches the candidate's gap. Near w3, positivity caps the parent pattern at M2 ≈ 4.24 (ρ_*^1.18 on 90 shells). Higher-M2 static bands exist only with other patterns, and that is the original static-GLL search, which is out of this campaign's scope.
