**Mechanism.** Controls (20261002T100543.282Z_ctrl-b_result_1de6, 20261002T112227.496Z_ctrl-b_result_5db5):
- static BZ-averaged density 1.022 on all clusters;
- static k = Γ density (M2 6.66) 0.66–0.72;
- static k = K density 0.92–0.99.
The gain needs the k-dependence, not a static density. Phase-only versions of the winning classes lose, so this is an amplitude-k-dependence effect. Caveats:
- the winners' PES entanglement gap is about 5 vs about 20 for the parent (still PASS at N_A = 2 and 3);
- 5×6 for the two single-k controls is still queued;
- an arbitrary-shape static density at M2 ≈ 4.85 is untested.

**Key lesson.** The star chart (all 36 (G, R) pairs of a star with one coefficient) hides the effect. It mixes one gaining class with losing ones (S1T1 star: +3 %; its perp class: +38 %). The orientation-class split (notes §5.7) is what found it.
