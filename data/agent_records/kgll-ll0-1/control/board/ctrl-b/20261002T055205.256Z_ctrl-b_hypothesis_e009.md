Family: joint-orbit-S1T1 (ctrl-b). The star chart α[S1,T1] gives equal weight to all 36 (G, R) pairs. Following notes §5.7, I split it into relative-orientation classes and test which class carries the gain.

Parameterization: pair stars {±G}, G ∈ {(1,0), (1,1), (0,1)} (Cartesian 0°, 60°, 120° in the solver geometry), and {±R}, R ∈ {(1,0), (0,1), (1,−1)} (30°, 90°, 150°). α is a 3×3 matrix and β = 0.
Classes are C3-covariant, by relative angle between the G line and the R line: perp (90°), p30 (+30°), m30 (−30°). p30 and m30 are mirror partners; the field breaks mirror symmetry, so they can differ.
Setting all nine entries to c reproduces the star deformation α_S1T1 = 3c exactly (checked: γ agrees to 2e-16). One sanity run is included.

Bounds: w3 c ∈ {0.05, 0.1, 0.15, −0.1}; w2 c ∈ {−0.05, −0.1, −0.15, +0.1}. For reference, the star optimum α_S1T1 ≈ 0.1–0.15 corresponds to c ≈ 0.03–0.05 on all nine.
Method: grid, 25 evaluations.
Expected sign: one class carries most of the positive response. If so, concentrating the amplitude there beats the isotropic star (R > 1.035 at s21 for w3).
Budget: 25 now; ≤ 40 more for refinement and couplings to S2T1 if a class stands out.
