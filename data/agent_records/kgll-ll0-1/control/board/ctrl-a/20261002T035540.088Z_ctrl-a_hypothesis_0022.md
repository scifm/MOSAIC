Family: ctrl-a/coord-w3 — one-coordinate map of the star-product deformation around w3.

Rationale. Doc 46 (Nk=21, g_cutoff 4) shows strongly asymmetric linear responses for w3:
alpha[S1,T1] = +0.05 -> +1.85 %, -0.05 -> -9.0 %; beta[S1,T1] = +0.05 -> -4.4 %; alpha[S3,T1] = +0.05 -> -3.75 %.
A large linear term means the s21 response surface is far from flat, so a signed coordinate map is the
cheapest way to find which (spatial star x momentum star x amp/phase) directions point uphill before any
joint search. Promotions are free, so the plan is to feed the ladder several *structurally different*
candidates with R_gap >= 1.02 at s21 and let r46/r56 test finite-size robustness, rather than polishing one.
I stay on the smoothest momentum harmonics (T1, then T2) because the 024 pilot's sign flip came from how
small clusters sample F(k).

Parameterization: gamma = sum (alpha/2 + i beta) O_S(r) F_T(k), solver-basis stars
S1,S2,S3,S4a,S4b (chiral halves of |G|^2=7),S5,S6,S8 x T1; S1,S2,S3,S6 x T2. n_mesh 48, g_cutoff 6
(= the converge-stage box, so no screening gain can come from box truncation).
Bounds (stage A): each coordinate alone at +-0.04 (alpha) and +-0.04 (beta); calibration S1T1 alpha = +0.03, +0.05.
Method: coordinate scan, 2 signs, then quadratic per-coordinate fits -> CMA-ES / local refinement in the
uphill subspace with box |alpha|,|beta| <= 0.15 (widened if winners pile at the edge).
Expected sign of R_gap - 1: positive along a few amplitude directions (S1T1 alpha>0 already), negative for most
phase directions (pilot + doc 46). Probability of a robust (r46+r56) positive: low; the 024 pilot reversed sign.
Budget: stage A ~50 evaluations, stage B up to ~150; the rest kept for w2 and for wider boxes.
