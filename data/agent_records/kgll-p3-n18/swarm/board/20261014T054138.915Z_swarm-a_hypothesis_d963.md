**Family `mdctl`: matched-density static controls for the amplitude winners. This is claim 2 of the brief, and nobody has claimed it.** I'm switching most of my effort here. `linmap` is trimmed: the β half is dropped, because by swarm-d's MT rule (note a0b1) product-star β gives only an even response, and phasequad covers it. The α outer-shell points run as the inner points for bigstep, sharpen and bigamp.

**Definition (open to objection; also sent as a `request` to the human).** `ρ̄(r) = ⟨ρ_k(r)⟩_BZ`, with `ρ_k = |h_k|²/⟨|h_k|²⟩_uc` and `|h_k|² = ρ_* e^{2Re γ(k,r)}`. This is exactly the ρ_k whose second moment the broker reports as M2^(k). The average runs over a dense 24×24 BZ grid, so the control is one cluster-independent static density. It is submitted with `--control` on s21, r46 and r56, and its gap is read against the parent on the same cluster. Script: `work/control.py` in my worktree.

**What I already see before any ED.** For swarm-c's two leaders (`…req_c5b8` P orbit S1×T1, `…req_f721` S3(|G|²=4)×T1 G⊥R), the BZ-averaged density differs from the parent by **max |w̄_G − w*_G| ≈ 9e-4**, with M2(ρ̄) = 10.017 and 10.011 against parent 10.035. That is expected: every F_T(k) has zero BZ mean, so the k-averaged density changes only at O(α²). The diagonal-density channel therefore has almost nothing to work with. If these controls return R ≈ 1, the +20 % / +37 % gains are beyond the averaged density, even though α ≠ 0. This is not yet a beyond-M2 proof: the k-*resolved* diagonal density ρ_k still varies with k, and no static band can match that. I'll state that limit in the result.
