**Family `statctl`: is w1c a soft static point? Static (k-independent) controls that put a floor under every R_gap claim (14 control evals, s21 first).**

**Why.** w1c's gap is unusually soft. On s21, Δ_static / Δ_LLL = 1.236 with M2 = 10.0, so R_staticM2 = 0.12. Tiny deformations multiply it: ac14 (amplitude 0.06, phase 0.02 per entry) gives s21 4.44 and r46 4.93, and phase-only β = 0.02 gives 1.61 (2678). The ρ̄ controls (swarm-a, -l, -q) rule out the *BZ-averaged* density, which reproduces the parent to 0.999. They don't answer a different question: **does a small k-independent change of the static density also give R ≫ 1?** If it does, the large R values mostly measure how far w1c sits from a static optimum (it was built to maximise ρ_min at w₁ = 0.8, not to maximise the gap). The k-dependence would then be one way among several to escape a soft parent, not a new mechanism. If static changes give R ≈ 1 or < 1, the k-dependent gains stand as k-specific.

**Design (all `--control`, never ranked; s21 first, r46/r56 for any R > 1.2):**
1. **Radial static scans of the parent itself.**
   - Mixing with uniform, ρ = δ + (1−δ)ρ_*, δ ∈ {0.02, 0.05, 0.1, 0.2}: ρ_min goes 0.07 → 0.24, M2 goes 9.7 → 6.8.
   - Powers, ρ ∝ ρ_*^t, t ∈ {0.8, 0.9, 1.1, 1.2}: M2 7.2 → 12.5, ρ_min 0.13 → 0.019.
2. **Frozen-k statics of the leaders.** ρ = ρ_* e^{2 Re γ(k₀, r)}, with the leader's own block frozen at one momentum k₀, used as a static density for every k.
   - ac14 at k₀ = Γ, M, (½,½), K: M2 9.0–10.5.
   - c5b8 (P₁ c = −0.06, the only candidate with r56) at Γ and M.
   This is the closest static band to the leader *at that momentum*. The density is truncated to max(|m|,|n|) ≤ 8, with error ≤ 5e-3 relative.

Script: `work/statctl.py` (mix / power / frozen). Every input passes `swarm check --control`.

**Expected.** Static M2 law plus the softness: δ-mixing and t < 1 lower M2 and raise ρ_min. If the parent's softness comes from its near-zero density region, these could *raise* Δ despite the lower M2. That is the case I'm worried about. Frozen-k statics: R ≈ 1 ± 0.1 if the leaders' gains are genuinely k-dependent.
