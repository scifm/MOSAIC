**Family `bigamp`: large-amplitude deformations that raise M2^(k) — does the Laughlin gap follow the k-resolved density sharpness?**

All three open families (`linmap`, `jorbit`, `jointorb`) are small-step local maps (|α| ≤ 0.1). The 024 pilot showed local responses ~0.5 %, below the finite-size spread, and the robust-positive bar is +5 % on both confirm clusters. Small steps are unlikely to reach that. I take the opposite end of the box: **large amplitude, up to the campaign boundary.**

**Measured lever (`swarm check`, `physics.kdep_envelope.m2_k_batch`, before any ED).** On w1c a single product term α·O_s(r)F_T1(k) changes M2^(k)/M2 as follows (α = −0.6 / −0.3 / +0.3 / +0.6):
- S1 (|G|²=1): 0.955 / 0.982 / 0.984 / 0.946. **S1 lowers M2^(k)** (w1 = 0.8 is already sharp).
- S3 (4): 1.138 / 1.037 / 1.034 / 1.125
- S4 (7): 1.533 / 1.160 / 1.174 / 1.586
- S7 (13): 1.868 / 1.245 / 1.328 / 2.168
- S10 (21): 1.973 / 1.245 / 1.386 / 2.632

T2 and T3 give the same M2^(k) to 3 digits. All of these pass admissibility. So the outer shells can push M2^(k) to 1.5–2.6 × the parent's, inside the boundary (≤ 3×). If Δ followed M2^(k) the way the static gap follows M2, R_gap would be well above 1.05. The pilot's prior points the other way: a k-dependent envelope breaks the h(r)·LLL (vortexable) structure that gives the static M2 law. So **this family measures how much of the sharpness gain survives the loss of vortexability.** That is a scientific result either way.

**Stage 1 (27 evals, screen s21), one product term at a time, amplitude only (β = 0):**
- S4, S7, S10 × T1: α ∈ {−0.3, −0.15, +0.15, +0.3, +0.6} (15)
- S2, S3 × T1: α = ±0.3 (4); S1 × T1: α = ±0.3 (2, the M2-lowering control)
- S5, S6, S8, S9 × T1: α = +0.3 (4)
- S7 × T2, S7 × T3: α = +0.3 (2, momentum harmonic at fixed M2^(k))

Box: single term, |α| ≤ 0.6 (the boundary); M2^(k)/M2 ≤ 2.7. Steps overlap linmap's only in sign, not in size, so the two maps join into response curves. I'll quote linmap's ±0.1 points where they exist rather than re-measure them.

**Stage 2 (~40–60 evals, after stage 1):** if R tracks M2^(k) for any shell, combine several outer shells (Σ|α| ≤ 2.5, M2^(k) up to 3×) and run a seeded, bounded CMA-ES there. If not, map R against M2^(k) across shells to get the "survival fraction" and abandon with that number.

**Caveats I will report.** (1) At α = 0.6 on S10, Re γ reaches ≈ 2.5 and the density factor spans ≈ e^{±5}. Truncation at g_cutoff 8 is then a real concern; the conv stage (g_cutoff 10, n_mesh 64) is the test, and I will treat any winner only after it. (2) Amplitude winners are not beyond-M2 by construction. Any candidate gets a matched-density static control `request`.

**Expected sign.** R − 1 > 0 for S4–S7 at moderate α (0.15–0.3), but well below M2^(k)/M2 − 1; S1 negative; T2/T3 worse than T1 at equal M2^(k), because the envelope varies faster in k. **Budget:** 27 + ≤ 60 evaluations.
