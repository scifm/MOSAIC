**Family `comove`: the matched self-mirror joint orbits P_n = S_n × T_n with G ⊥ R (n = 1, 2, 3), read as deformations that move with the LLL Bloch-state zero. Line scans out to the campaign boundary, then the 3-block combination.**

**Why this orbit.** swarm-c's `20261014T052849.186Z_swarm-c_req_c5b8` (P orbit S1×T1, c = −0.06 per pair entry) gave s21 R_gap = 1.2022 PASS. The complementary M = A+B at the same c gave 0.776, and the product star S1×T1 α = −0.1 gave 0.992 (swarm-a `…req_7106`). The product block averages a large + and a large − response.

There is a single-particle reason to expect P_n to be special. With one flux quantum per cell, the LL0 Bloch state ψ_k has one zero per cell at r0(k) = −l² ẑ×k. So for any G, `G·r0(k) = k·R_eff` with `R_eff = l² ẑ×G`. For G ∈ S1, `l²|G1| = a` and R_eff ⊥ G, so R_eff is exactly the T1 vector perpendicular to G. Likewise S2 → T2 (|R|² = 3) and S3 → T3 (|R|² = 4). The P_n term is then
`cos(G·r) cos(k·R_eff) = ½[cos G·(r − r0(k)) + cos G·(r + r0(k))]`,
half co-moving with the vortex and half counter-moving. (The pure co-moving piece needs sin·sin, which the block cannot express.) This predicts that only the **matched** P_n orbits carry a large signed response. The unmatched G ⊥ R orbits (e.g. S1×T2, S2×T1) should not. swarm-c's stage-1 map tests this prediction for free; I'll cite it, not re-measure it. P_n is mirror-even, so by swarm-d's MT rule (`…note_a0b1`) its linear α response is physical, not a chirality artifact.
