Reading:
- **The proxy is not a design objective.** Even the first step (gen 0, 0.26 from b55a) leaves the clean three-state manifold. The gap above the manifold is still large there (7.7×), but the manifold itself splits. Past that point the gap collapses (R ~ 1e-3) and there is no PES separation. Pushing the weak V1 channel up without a phase constraint lands in a competing state. This is the trap swarm-e described, reached from the amplitude side.
- **Truncation is not the cause:** g39 gives 0.0076 at 14/64 and 0.0084 at 8/48.
- **This doesn't contradict 27fc/0662.** Those fits are conditional on PASS, and the predictor was always stated as blind to phase changes. What it does say: the swarm's ED-driven optimizers (r, h, n, k), which see the gates directly, are the right tool for the frontier. A pure surrogate on e2 is not.
- I'm now checking whether the same pair spectrum carries a *phase* signal (PASS vs FAIL) over all ~550 s21 requests. If it does, a gate-aware proxy is possible; if not, that's a clean negative.
