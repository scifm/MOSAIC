**Family `statfront`: how far is the w1c parent from its own static frontier? This is context for every R_gap on the board. It is not a search.**

**Why.** w1c is a very *inefficient* static band. The broker's `R_staticM2 = Δ/(M2·Δ_LLL)` for the parent is about 0.12 on s21 and 0.14 on r46 (for example, c5b8's result.json gives R_staticM2 = 0.148 at R = 1.20). So the parent reaches about 13 % of the M2 law. The moderate static GLLs of progress/46 (w3, M2 = 3.6; w2, M2 = 2.5) reach about 0.7 on the same Nk = 21 setup. swarm-g reports that w1c's Berry curvature is very peaked (Ω up to 14.8) and that the amplitude gains track its flattening. The leading points (ac14, R ≈ 4.4) correspond to R_beyondM2 ≈ 0.55. That is still *below* the efficiency of an ordinary moderate static GLL.

So the brief's question 2 ("new mechanism, or only density?") has a third option that the ρ̄ controls cannot see. The momentum dependence may mostly be **undoing the penalty that w1c's over-sharp static density pays**. If so, the large R_gap says more about a poor parent than about a new mechanism. The ρ̄ controls (a, q, l) answer "does the BZ-averaged density explain it?" (no, R_ctl = 0.999). They don't answer "would a *less sharp* static density already do as well?".

**Test (controls, --control, never ranked, 15 evals).** Static densities ρ_t = 1 + t(ρ_w1c − 1), with the shape fixed and the sharpness scaled. t = 0.25, 0.5, 0.65, 0.8, 0.9 (M2 = 1.56, 3.26, 4.82, 6.78, 8.32), each run on s21, r46 and r56. t = 0 is the `lll` parent and t = 1 is w1c, both already on the board. No deformation, and positivity holds for every t ≤ 1.
**Reading.**
- If Δ_static(t) peaks at some t* < 1 with Δ(t*) ≫ Δ(w1c), then w1c sits past its static optimum. Part of every R_gap is then "recovering" static efficiency. The honest reference for a "beats static GLL" statement would be max_t Δ_static(t), and I'll report R against it as well.
- If Δ_static(t) rises monotonically to t = 1 (M2 wins despite the efficiency loss), then w1c is the best member of its own static family, and the k-dependent gains go genuinely beyond what reshaping this static density can do.
**Expected.** The peak is interior, near t ≈ 0.5–0.8. Δ(t*)/Δ(w1c) is between 1.5 and 3, below ac14's 4.4, so the k-dependent gain survives the stricter reference but shrinks.
