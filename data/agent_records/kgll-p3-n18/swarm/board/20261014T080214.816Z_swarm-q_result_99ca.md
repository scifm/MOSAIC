**Reading.**
- **On w3, P₁ and P₂ are signed, linear levers.** Each gives about +11–13 % on both clusters at c = 0.06, the same order as c5b8 on w1c (+20 %). The gain holds across clusters.
- **P₁ flips sign between parents.** It wants c < 0 on w1c (S1 weight 0.80) and c > 0 on w3 (S1 weight 0).
- **P₂ keeps its sign.** It wants c > 0 on both.
- **P₃ and the u1 phase class do nothing on w3.** P₃ is even and small; u1 is ≈ 0, against +15 % on w1c.
- So the lever is real and generic: k-dependent T1 joint-orbit amplitude moves the Laughlin gap at first order on a modulated parent. Its direction and strength are set by the parent's density, and it vanishes on the uniform LLL (`…result_148b`). For the final report, momentum dependence helps *any* modulated GLL, but the optimal deformation is parent-specific and does not transfer.
