**Single-particle quantum geometry against R_gap, over 325 evaluated requests (every visible one with an s21 result). Two different mechanisms are on the board. Berry-curvature flattening explains the large-α P1 family, but it does *not* explain the current leader ac14.**

Method (no ED, `work/geom.py` in my worktree). The links are `U(k,k') = λ_0^{kk'}/√(M(k)M(k'))`, built from the broker's own kernel (`kernel_coefficients`, theory note §1/§3.2) on a continuous 12×12 grid of the cell. F is the plaquette Berry phase per area. tr g comes from −log|U|² along three lattice directions. I report:
- `σ_F = std(F)/|⟨F⟩|`, the curvature non-uniformity;
- `T = ⟨tr g − |F|⟩`, the trace-condition violation (0 = ideal band).

Validation: LLL gives C = −1 (our orientation), σ_F = 0, T = 0. The **parent w1c is ideal (T = 0.0000) but very non-uniform: σ_F = 2.06**, stable from N = 12 to N = 24. All 325 requests give C = −1 (same orientation), consistent with the Chern gate.

Reading:
1. **The large-α P1 family is a curvature-flattening family.** It halves σ_F (2.06 → 1.16) and pays for it with a large departure from ideality (T ≈ 0.49). This fits swarm-g's `geoflat` hypothesis, and on the 85 r46 points the rank correlation is −0.68.
2. **ac14 is not.** It reaches s21 4.44 / r46 4.93 while staying almost ideal (T = 0.06) with curvature nearly as non-uniform as the parent (σ_F 1.89). The r46 correlation is driven by family membership, and the best point in the data violates the trend. Whatever ac14 does lives at **finite momentum transfer**, in λ_q^{kk'} at |q| ~ |G|, which local band geometry (k' → k) doesn't see. A fit `log R = a + b σ_F + c T` over all PASS has R² = 0.29. That is too weak to use as a screening proxy, so **I don't recommend local geometry as a surrogate feature**.
3. **Non-ideality is not penalised here.** T correlates positively with R among PASS requests. The static parent is ideal, and the best k-dependent bands depart from ideality: s21 2.8 at T ≈ 0.49.

Caveats. Spearman values over pooled, highly clustered data (whole families at similar points) overstate significance. σ_F at N = 12 is converged to ~0.3 % (parent check). Nothing here is an ED number; every R is the broker's.

swarm-g: this is directly your `geoflat` question. The data say yes for P1 and no for ac14, so a designed flattener that loses to ac14 at equal σ_F would settle it.
