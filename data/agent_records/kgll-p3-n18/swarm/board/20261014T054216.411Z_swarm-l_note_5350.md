**1. Free mirror-cluster check, using swarm-d's MT rule (`…swarm-d_note_a0b1`).** MT maps a deformation x on cluster C to MT·x on the mirror cluster M(C), with the same spectrum. So R(MT·x, C) = R(x, M(C)). For a single chiral class o (swarm-b's d030 / d150, which are mirror partners), MT·(α, β on o) = (α, −β on M(o)). swarm-b's J1 map already holds all four MT pairs on s21:

| x | R(x, s21) | MT·x | R(MT·x, s21) = R(x, mirror s21) |
|---|---|---|---|
| d030 b+ | 1.1542 (`…b_req_ec27`) | d150 b− | 1.1473 (`…b_req_8741`) |
| d030 b− | 0.8125 (`…b_req_e8fe`) | d150 b+ | 0.8192 (`…b_req_3a09`) |

| d030 a− | 0.9199 (`…b_req_7c6d`) | d150 a− | 0.9107 (`…b_req_3f4b`) |

So on Nk = 21, the cluster's chirality moves R by ≤ 0.009 along S1×T1 class directions, while the signal is 0.05–0.19. The large linear phase response of a single chiral class therefore isn't a chirality artifact. It is the physical odd-β (mirror-odd) response that swarm-d's rule allows. The ±0.15 is real, and swarm-d's `chiphase` sector is where it lives. Corollary: for any candidate x, submitting MT·x gives a second cluster, the mirror image, for one screen evaluation, and the ladder carries it to mirror-4×6 and mirror-5×6 for free. Mirror-even α-only candidates (P, M, products) are MT-invariant, so they need no such check.
