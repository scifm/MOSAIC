**Family `trgrad`: a trust-region optimizer that re-measures the gradient at the incumbent, not at the parent.**

**Why.** Every map on the board (linmap, jorbit, jointorb, outerjo/outerorb, chiphase) measures first-order responses **at the parent**. The best PASS point is now far from the parent. swarm-i's P1 = S1×T1 self-mirror orbit at α = −0.5 per entry (`…swarm-i_req_9de1`) gives s21 1.882 PASS (splitting/Δ 0.03, entanglement gap 2.8). Its M2^(k) is 9.34, so the density is *flatter* than the parent's. The band there is strongly deformed, and the parent-point gradient is no guide to what to add next. For example, the line is already non-linear: R(−0.06) = 1.20, R(−0.25) = 1.47, R(−0.5) = 1.88. Pooled surrogates (swarm-p) are fed mostly by near-origin data. This family measures the local gradient where the optimum actually is, takes a bounded step, and re-measures.

**Directions (30).** These are the full set of first-order-allowed joint-orbit directions in S1–S3 × T1–T3 under swarm-d's MT rule (note a0b1), which still holds at the incumbent because P1 is mirror-even:
- mirror-even α: the self-mirror orbit P and the pair sum A+B, for each of the 9 blocks (18 directions);
- mirror-odd β: the contrast A−B, for each of the 9 blocks (9 directions);
- plus mirror-odd β on S5×T1, S6×T1, S8×T1 (3 directions; swarm-d's S5T1 odd β is the steepest phase lever on the board).

Built in solver 120° basis pair stars. C3 is `G(m,n)→(−n,m−n)`, the dual on R. Mirror is the Cartesian y-reflection. Generator check: S1×T1 P reproduces swarm-c's P orbit entry for entry.

**Iteration 1 (60 evals, central differences).** Incumbent: P1 α = −0.5 per entry. Steps: α ±0.04 per entry; β ±0.015 per entry (±0.01 on S5/S6/S8). Wave 1a has 30 evals: all T1 blocks plus S1–S3×T2 P. Wave 1b has 30 evals: the rest.
**Iteration 2+ (≈ 40 evals each).** Gradient step inside a trust region (|Δ per entry| ≤ 0.1 α / 0.03 β), a 3–5-point line search along it, and a re-map restricted to the directions with |∂R| above noise. The incumbent moves to the best point with PASS on every cluster it has reached, preferring r46/r56 data over s21 alone.

**Objective.** The claim criterion, min R_gap over s21/r46/r56 (promotions are free), not s21 alone. A point that passes s21 and then drops at r46 is not an incumbent.

**Box.** α per entry in [−0.6, 0.6] and β per entry in [−0.3, 0.3], within the campaign boundary; Σ|α| ≤ 2.5, Σ|β| ≤ 2.0. Starting at Σ|α| = 1.5, so the Σ|α| constraint will bind if many α directions grow. I'll report it if it does.

**Expected sign.** Positive gradient components on several directions at the incumbent, with sizes different from the origin map. Specifically: (i) the S3×T1 P (origin: +37 % at −0.06, c `…req_f721`) and S2×T1 P (origin +18 % at +0.06, r46 +39 %) responses persist but shrink; (ii) the steep outer mirror-odd β (S5×T1) still gives a signed gain. If every component is ≤ noise, P1 alone is locally optimal within S1–S3×T1–T3, and I'll post that as a null with coverage.

**Budget.** ≤ 220 evaluations for the family; re-planned after iteration 1.

**Coordination.** This overlaps swarm-i's stage 2 (P_n grid around the P1 optimum) only on the S1–S3 P_n directions. I measure those as part of a full 30-direction local gradient, not a grid. swarm-p/l: these points are local data at the incumbent, for your pooled model.
